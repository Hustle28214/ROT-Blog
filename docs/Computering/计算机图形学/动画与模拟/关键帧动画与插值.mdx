# 关键帧动画与插值：让离散时刻长出连续曲线

动画的本质是欺骗：以每秒 24/30/60 张画面骗过视觉暂留。手绘时代动画师逐帧画，成本按帧线性增长。迪士尼在 1930 年代摸索出了"关键帧+中间帧"分工——首席动画师只画关键姿势（keyframes），中间帧（inbetweens）由助手完成。计算机图形学几乎原封不动继承了这套流程，只不过中间帧的插值从人手改成了**数学插值函数**。

关键帧动画的整个理论骨架，就是"给定几个离散时刻的值，如何生成一条经过或近似经过它们的连续曲线"。这个问题在数值分析里叫**插值**（interpolation）与**逼近**（approximation）。图形学从这个数学工具箱里挑了几件顺手的，然后针对旋转、缓动这些特殊场景做了定制。

## 1. 从 lerp 说起

线性插值（linear interpolation, **lerp**）是所有插值的原点：

$$
\mathrm{lerp}(a, b, t) = (1-t)\,a + t\,b, \quad t\in[0,1]
$$

$t=0$ 得 $a$，$t=1$ 得 $b$，中间是直线。这个公式对标量、向量、颜色、位置全都成立——只要目标类型是线性空间（支持加法和标量乘法）就行。GPU 里的重心插值、纹理采样、屏幕空间插值本质上都是 lerp。

lerp 的问题在于它太"直"。给两个位置关键帧，中间是匀速直线——这不像任何真实运动。真实物体有加速度、有惯性、有摩擦。所以关键帧动画不满足于 lerp，要么把关键帧塞得很密（让每段直线足够短），要么把 lerp 换成更复杂的曲线。

## 2. slerp：旋转的正确插值

给一个物体的两个方向（比如向左看和向右看），中间怎么过渡？如果用欧拉角做 lerp——分别插值 pitch/yaw/roll——会遇到万向锁和路径不最短的问题。如果用旋转矩阵 lerp——每个元素独立插值——插出来的中间矩阵不再是正交矩阵，物体会被拉伸变形。

正确答案是**四元数球面线性插值**（Spherical Linear intERPolation, **slerp**）。两个单位四元数 $q_1, q_2$ 是四维单位球面上的两个点，它们之间的最短路径是球面上的大圆弧。参数化这条弧就得到：

$$
\mathrm{slerp}(q_1, q_2, t) = \frac{\sin((1-t)\Omega)}{\sin\Omega}q_1 + \frac{\sin(t\Omega)}{\sin\Omega}q_2
$$

其中 $\cos\Omega = q_1\cdot q_2$ 是两个四元数的夹角。slerp 有几个好性质：

- **恒定角速度**：$t$ 均匀走时，旋转角速度是常数（匀速旋转）
- **最短路径**：走的是四维球面上的测地线
- **保持单位模**：中间四元数始终在单位球面上，不需要重新归一化

四元数有个符号歧义——$q$ 和 $-q$ 表示同一个旋转。slerp 前要检查 $q_1\cdot q_2$ 的符号，如果是负的就把 $q_2$ 取反，否则会绕远路（走 $360°-\theta$ 而不是 $\theta$）。

当 $\Omega$ 很小时 $\sin\Omega$ 接近 0，公式数值不稳定，工程上会回退到 lerp+归一化（**nlerp**）。nlerp 走的是弦而不是弧，角速度不均匀，但便宜。90% 的游戏引擎在小角度下都这么干。四元数本身的数学参见 [向量与矩阵：图形学的数学基石](../图形学数学基础/向量与矩阵：图形学的数学基石.mdx)。

## 3. 样条：让曲线光滑地穿过多个点

两个关键帧之间 lerp/slerp 就够了，多个关键帧就得考虑**连续性**。给出 4 个位置关键帧，直接把三段 lerp 拼起来，在关键帧处会出现速度突变（$C^0$ 连续但不 $C^1$）——物体走到关键帧突然拐弯，视觉上就是抽搐。

样条（spline）是分段多项式，通过约束每一段与相邻段在连接点处的导数，让整条曲线保持 $C^1$ 甚至 $C^2$ 连续。

### 3.1 三次 Hermite 样条

每段用一个三次多项式，由两个端点位置 $p_0, p_1$ 和两个端点切线 $m_0, m_1$ 确定：

$$
p(t) = h_{00}(t)p_0 + h_{10}(t)m_0 + h_{01}(t)p_1 + h_{11}(t)m_1
$$

其中 Hermite 基函数：

$$
\begin{aligned}
h_{00}(t) &= 2t^3 - 3t^2 + 1 \\
h_{10}(t) &= t^3 - 2t^2 + t \\
h_{01}(t) &= -2t^3 + 3t^2 \\
h_{11}(t) &= t^3 - t^2
\end{aligned}
$$

Hermite 曲线的优点是**局部控制**——改一个点或一个切线只影响相邻两段，不影响远处。3D 建模软件里的动画曲线编辑器（Maya 的 graph editor、Blender 的 F-Curve）本质上都是 Hermite 曲线，用户拖切线控制柄。

### 3.2 Bézier 曲线

三次 Bézier 用 4 个控制点 $P_0, P_1, P_2, P_3$：

$$
B(t) = (1-t)^3 P_0 + 3(1-t)^2 t\, P_1 + 3(1-t)t^2 P_2 + t^3 P_3
$$

曲线经过 $P_0$ 和 $P_3$，但**不**经过 $P_1$、$P_2$——后两者是切线控制点。$P_1 - P_0$ 和 $P_3 - P_2$ 就是首尾切线的方向和长度。

Bézier 和 Hermite 是数学等价的，用一个 $4\times 4$ 矩阵就能相互转换。选择哪种表达取决于交互习惯——设计师喜欢拽 Bézier 的切线控制柄（Illustrator、CSS 的 `cubic-bezier` 都是这套）；动画曲线编辑器上更常见 Hermite 的 in/out 切线概念。

### 3.3 Catmull-Rom：只给关键帧

Hermite 和 Bézier 都要求用户同时提供切线。有些场合只有位置关键帧（比如相机飞跃路径 waypoints），懒得手工调切线。**Catmull-Rom** 用邻居自动算切线：

$$
m_i = \frac{P_{i+1} - P_{i-1}}{2}
$$

即每个关键帧的切线取"前一点到后一点"方向的一半。曲线经过所有关键帧（interpolating，不是像 Bézier 那样 approximating），并且 $C^1$ 连续。这是相机路径、粒子轨迹、Unity 里 `TrailRenderer` 默认曲线的做法。

Catmull-Rom 有个变种 tension/continuity/bias（TCB 样条），三个参数分别控制切线幅度、连续性、方向偏置。3ds Max 的默认插值就是 TCB。

不同样条族的对比：

| 样条 | 经过控制点 | 局部控制 | 连续性 | 典型用途 |
|---|---|---|---|---|
| Linear | 是 | 是 | $C^0$ | 网格顶点、简易动画 |
| Hermite | 是 | 是 | $C^1$ | Maya/Blender 动画曲线 |
| Bézier | 端点 | 是 | $C^1$ | Illustrator 路径、字体 |
| Catmull-Rom | 是 | 是 | $C^1$ | 相机路径、waypoints |
| B-Spline | 否 | 是 | $C^2$ | CAD、平滑轮廓 |

## 4. 缓动：不匀速的匀速

即使用 lerp 把关键帧连起来，动画师仍然要控制"节奏"——加速开始、减速结束、弹性回弹。这套时间重映射函数叫**缓动**（easing）。

缓动的本质是把标准 $t\in[0,1]$ 变成 $t'=f(t) \in [0,1]$，$f$ 是单调递增、经过 $(0,0)$ 和 $(1,1)$ 的函数。然后用 $t'$ 去 lerp。

Robert Penner 在 1990 年代整理的经典缓动函数一直沿用至今：

```
ease-in       快开始   ────╱
                          ╱
                    ─────╱

ease-out      慢开始   ╱─────
                     ╱
                    ╱────

ease-in-out   两端慢   ────╮   ╭────
                          │   │
                           ╲─╱
```

数学形式最常见的几个：

- **quadratic ease-in**：$f(t)=t^2$
- **cubic ease-in-out**：分段 $f(t)=4t^3$ 或 $1-(-2t+2)^3/2$
- **exponential**：$f(t)=2^{10(t-1)}$，开头几乎不动，最后突然冲
- **elastic**：带阻尼正弦，模拟弹簧
- **bounce**：模拟球落地反弹，分段抛物线

CSS 里的 `cubic-bezier(0.25, 0.1, 0.25, 1)` 是 Bézier 缓动——把缓动曲线本身用 Bézier 描述，两个控制点就是那四个数。iOS 的 `UIViewAnimationOptionCurveEaseInOut` 底层也是 Bézier。

缓动是低成本高回报的动画技巧。同一段直线运动加不同缓动，观感差别可以从"呆板机械"变到"充满生机"。Disney 的 12 条动画基本原则里，slow in / slow out 和 anticipation 都本质上是缓动。

## 5. 动画曲线编辑器

生产环境里动画师不是写公式，而是在**曲线编辑器**里可视化编辑。X 轴是时间（帧数或秒数），Y 轴是被动画的属性（位置分量、旋转分量、材质参数、任意浮点数）。每个关键帧是曲线上的一个点，可以拖它的位置也可以拖切线。

一个骨架动画可能有几百根骨骼、每根 9 或 10 个通道（位置 3 + 旋转 4 + 缩放 3），一段战斗动画就是几千条曲线。存储上这些曲线通常压缩为关键帧数组+切线信息，播放时按当前时间做二分查找找到当前段，然后 Hermite 插值。

**曲线剪辑与混合**（animation blending）是另一层：多段动画曲线加权平均，实现"边跑边射击"这类组合。混合权重本身也是被动画的曲线——曲线套曲线，图形工程师的日常。

## 6. 一段跳跃动画的分解

考虑一个角色跳跃，从起跳到落地约 1 秒。分析一下每个通道该用什么插值：

1. **躯干高度 Y**：抛物线运动，物理上是 $y(t)=v_0 t - \frac{1}{2}g t^2$。可以用 3 个关键帧（起、顶、落）+ Bézier 拟合，或者直接算物理。
2. **躯干水平 X**：如果向前跳，$X$ 是近似匀速，lerp 就够。加个 ease-out 让落地时略微减速更真实。
3. **膝盖旋转**：起跳前要蹲下（anticipation），空中收腿，落地缓冲——4-5 个关键帧，Hermite 曲线。
4. **头部朝向**：跟随躯干但有滞后，用四元数 slerp。滞后可以通过在时间轴上偏移几帧实现。
5. **手臂摆动**：与腿反相，正弦函数即可，不需要关键帧。

拆分后每个通道独立编辑独立播放，最后叠加成完整动画。这就是**通道分离**的意义——设计师改一个通道不影响别的。

关键帧动画只是动画管线里的一环。下游它对接：

- **动画状态机**：Idle/Walk/Run/Jump 之间的切换本质是"从这段曲线过渡到那段"，过渡时间内用 lerp/slerp 混合

理解了插值的数学，动画就不再是"魔术"，而是一堆时间函数的组合。剩下的工作是审美——什么时候放关键帧、切线怎么拉、缓动怎么调——这部分永远交给动画师而不是工程师。
