> **L7 选型与混合层**（进阶）：BT 做执行层；规划、评分、大模型各归其位。

## 大纲

### 1. 分层心智模型
```text
意图 / 任务目标
    ↓  LLM 或任务管理器
符号计划 / 技能序列          ← GOAP / HTN / 任务规划器
    ↓
行为树执行 + 反应式中断      ← BT
    ↓
运动控制 / 夹爪 / 导航
```

### 2. BT + FSM
- FSM 管大模式：空闲 / 任务中 / 充电 / 故障
- 每个模式内一棵 BT
- 或 BT 顶层 Selector 模拟模式，局部仍可用小组 FSM（如技能内部）

### 3. BT + GOAP / HTN
- 规划器输出：有序技能列表或子目标
- BT 负责：执行、重试、反应、失败上报
- 重规划触发：BT Failure、环境事件、超时

### 4. BT + Utility AI
- Utility 给多个候选子树打分，Selector 按分选择
- 或 Decorator 根据效用动态启用
- 适合“多种合理行为、需权衡”的场景（交互、巡检路线）

### 5. BT + LLM
| LLM 适合 | LLM 不适合 |
| :--- | :--- |
| 解析自然语言任务 | 每控制周期直接出关节角 |
| 生成/改写树或参数 | 安全相关硬实时决策 |
| 失败后解释与建议重试 | 替代急停与互锁 |

模式：LLM 产出结构化技能图 → 编译成 BT 子树 → 实机只跑 BT。

### 6. 选型表（给团队）
| 需求 | 优先方案 |
| :--- | :--- |
| 步骤固定、要反应式 | 纯 BT |
| 目标组合多变、世界符号清晰 | HTN/GOAP + BT |
| 多欲望权衡 | Utility + BT |
| 开放语言任务 | LLM + BT 执行 |
| 局部协议简单 | 小组 FSM |

### 7. 反模式
- 用 BT 硬编码长时域搜索
- 用 LLM 替换整棵执行树的每一步
- 规划频率过高导致树频繁重置抖动
