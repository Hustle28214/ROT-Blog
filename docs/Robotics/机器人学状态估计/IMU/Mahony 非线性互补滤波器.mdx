## 1. 数学推导

### 1.1 陀螺仪模型

MEMS 陀螺仪利用科里奥利效应（Coriolis effect）测量角速度——内部一个以固定频率振动的质量块，在载体发生转动时会受到与角速度成正比的科氏力，由此感应出与角速度成正比的电信号。因此，理想情况下陀螺仪的输出正比于机体坐标系下的真实角速度 $\Omega$。

为什么不能直接把测量值当真值? 实际传感器输出总会受到两类误差的污染，需要在建模中显式地表示出来：

1. **确定性误差（可估计、可补偿）**：制造工艺缺陷、温度漂移、电路失调等，会让传感器在**零输入**时输出一个非零的、缓慢变化的值。这一分量在短时间内近似为常数，但会随时间/温度慢变，通常建模为一个可估计的状态量 $b$（Bias，零点偏置）。实际使用的时候温漂占误差的大头。
2. **随机误差（不可预测、只能建模其统计特性）**：电子元件的热噪声、量化噪声等高频扰动，无法精确预测每个时刻的值，只能用一个零均值的随机过程 $\mu$ 来描述，通常我们把它假设为高斯白噪声。

将真值、确定性误差、随机误差三者线性叠加，就得到陀螺仪的**加性误差模型（Additive Error Model）**：

数学语言表示：

$$
\Omega_y = \Omega + b + \mu \in \mathbb{R}^3
$$

其中：

- $\Omega_y$：陀螺仪测量值（机体坐标系下的角速度）
- $\Omega$：真实角速度（机体坐标系下的角速度）
- $b$：陀螺仪零点偏置（Bias），慢变量，需要在线估计
- $\mu$：陀螺仪测量噪声（Noise），零均值随机过程，只能滤波抑制

:::note 建模思路
这类"真值 + 慢变偏置 + 白噪声"的加性模型，是惯性传感器最经典的一阶误差模型。它把误差**按时间尺度分离**：可估计的慢变量 $b$ 交给滤波器（如 Mahony 的积分项 $K_i$）在线学习并补偿；不可估计的高频噪声 $\mu$ 交给低通/融合结构去衰减。后面加速度计模型采用完全相同的思路。
:::

### 1.2 加速度计模型

MEMS 加速度计的核心是一个"弹簧–质量块–阻尼"结构。质量块被弹性梁悬挂在传感器壳体内，外界给壳体施加加速度时，惯性会让质量块相对壳体产生位移，电容/压阻电路把这个位移读出来。**关键点**：如果一个物体处于自由落体状态，质量块相对壳体不产生位移，加速度计输出为零——也就是说，加速度计**不测坐标加速度**，而是测所谓的**比力（Specific Force，或称非引力加速度）**：单位质量所受到的、除重力以外的合外力。

从牛顿第二定律推导，设载体在惯性坐标系（Inertial / World frame，记为 W 系）下的速度为 $v$，其真实的坐标加速度即为 $\dot v$。作用在质量块上的力分成两部分：重力与"其它所有力"（弹簧的支持力等）。根据牛顿第二定律：

$$
m \dot v = f + m g_0 \;\;\Rightarrow\;\; f / m = \dot v - g_0
$$

加速度计感知的正是 $f/m$，即**去掉重力后的加速度分量**，这就是"比力"的物理定义。这一量目前还写在惯性系下，需要旋转到机体坐标系（Body-fixed frame，记为 B 系）——因为传感器是**跟着机体一起转**的，它输出的一定是机体系下的分量。记 $R \in SO(3)$ 为把机体系向量映射到世界系的旋转矩阵（即 $v^W = R\, v^B$），则其转置 $R^T$ 完成 W 系到 B 系的坐标变换。

**加入误差项**：与陀螺仪完全同构，加速度计的输出同样受慢变偏置和高频噪声污染。把三者线性叠加，即得**加速度计的加性误差模型**：

$$
a = R^T (\dot v - g_0) + b_a + \mu_a \in \mathbb R^3
$$

其中：

- $a$：加速度计测量值（机体坐标系下的比力）
- $R \in SO(3)$：机体系到世界系的姿态旋转矩阵
- $\dot v$：载体在世界坐标系下的真实线加速度
- $g_0 = [0, 0, -g]^T$：世界系下的重力加速度矢量（约定 z 轴向上时的写法）
- $b_a$：加速度计零点偏置（Bias），慢变量
- $\mu_a$：加速度计测量噪声（Noise），零均值随机过程

:::tip 为什么加速度计能当"重力方向传感器"用？
当载体处于**静止或匀速运动**（准静态假设）时，$\dot v \approx 0$，此时忽略偏置与噪声后模型退化为：

$$
a \approx -R^T g_0
$$

这意味着加速度计的读数**直接给出了重力矢量在机体系下的投影方向**。而重力方向在世界系里是已知常量 $g_0$，两者一比对，就能反解出姿态 $R$ 中的**俯仰角（Pitch）与横滚角（Roll）**——航向角（Yaw）无法被重力观测约束，这也是纯 6 轴 IMU（陀螺 + 加速度计）只能估计两轴姿态、需要磁力计才能补齐 Yaw 的根本原因。

Mahony 滤波器正是利用这一点：把**加速度计测得的实际重力方向**与**由当前四元数预测的重力方向**做叉乘构造误差，再用这个误差反过来修正陀螺仪积分的漂移——这就是后文代码里【第二步】到【第四步】的物理由来。
:::

:::warning 准静态假设的失效
当载体存在明显机动（急加速、震动、离心运动）时，$\dot v$ 不再可忽略，加速度计读数中掺入了非引力加速度，此时若仍按"重力方向"来用，会带来严重的姿态误差。这也解释了为什么 Mahony 中的比例增益 $K_p$ 不能设得过大——它反映了我们对加速度计"当前是否真的在测重力"的信任度。
:::





## 2. 代码实现

```python
import numpy as np

# 1. 核心调参参数
Kp = 2.0      # 比例增益：控制加速度计纠正陀螺仪漂移的速度（越大收敛越快，但怕震动）
Ki = 0.005    # 积分增益：消除陀螺仪的固有零点偏置（常置一个极小的值，不需要时可设为 0）

# 2. 内部全局变量（用于积分项累加误差）
e_integral_x = 0.0
e_integral_y = 0.0
e_integral_z = 0.0

def mahony_update_6dof(q, gx, gy, gz, ax, ay, az, dt):
    """
    q: 当前姿态四元数 [qw, qx, qy, qz]
    gx, gy, gz: 陀螺仪角速度 (单位: rad/s)
    ax, ay, az: 加速度计数据 (任意单位，只要是三轴即可)
    dt: 采样时间间隔 (单位: 秒)
    """
    global e_integral_x, e_integral_y, e_integral_z
    qw, qx, qy, qz = q

    # 【第一步】归一化加速度计数据
    norm = np.sqrt(ax**2 + ay**2 + az**2)
    if norm == 0.0: return q  # 处理异常
    ax, ay, az = ax / norm, ay / norm, az / norm

    # 【第二步】提取当前四元数姿态下的“理论重力方向”
    # 这是四元数旋转矩阵的第三列转置，代表地理坐标系下的 [0, 0, 1]（重力）转到机体坐标系的值
    vx = 2.0 * (qx * qz - qw * qy)
    vy = 2.0 * (qw * qx + qy * qz)
    vz = qw**2 - qx**2 - qy**2 + qz**2

    # 【第三步】通过向量叉乘（Cross Product）计算误差
    # 实际重力 [ax, ay, az] 与 理论重力 [vx, vy, vz] 的叉乘，反映了姿态的偏差方向和大小
    ex = (ay * vz - az * vy)
    ey = (az * vx - ax * vz)
    ez = (ax * vy - ay * vx)

    # 【第四步】PI 控制器：对误差进行比例和积分
    if Ki > 0.0:
        e_integral_x += ex * dt
        e_integral_y += ey * dt
        e_integral_z += ez * dt
    else:
        e_integral_x, e_integral_y, e_integral_z = 0.0, 0.0, 0.0

    # 将误差补偿应用到陀螺仪数据上
    gx += Kp * ex + Ki * e_integral_x
    gy += Kp * ey + Ki * e_integral_y
    gz += Kp * ez + Ki * e_integral_z

    # 【第五步】用补偿后的角速度更新四元数微分方程
    q_dot_w = 0.5 * (-qx * gx - qy * gy - qz * gz)
    q_dot_x = 0.5 * ( qw * gx + qy * gz - qz * gy)
    q_dot_y = 0.5 * ( qw * gy - qx * gz + qz * gx)
    q_dot_z = 0.5 * ( qw * gz + qx * gy - qy * gx)

    # 积分得到新的四元数
    qw += q_dot_w * dt
    qx += q_dot_x * dt
    qy += q_dot_y * dt
    qz += q_dot_z * dt

    # 【第六步】归一化四元数并输出
    norm = np.sqrt(qw**2 + qx**2 + qy**2 + qz**2)
    return [qw / norm, qx / norm, qy / norm, qz / norm]
```
