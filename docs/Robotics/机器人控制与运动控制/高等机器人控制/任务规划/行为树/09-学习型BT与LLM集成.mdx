> **L9 研究 / 前沿层**（专题）：反应式规划、学习型 BT、LLM 集成与可解释性。超过这层多半是论文或特定引擎细节。

## 大纲

### 1. 为什么还要“学习”行为树
- 手工设计树：可靠但贵
- 环境与任务多样：希望自动生成结构或参数
- 仍想保留：可解释、可约束、可中断——相对纯端到端策略的优势

### 2. 学习什么
| 对象 | 例子 |
| :--- | :--- |
| 参数 | 超时、重试次数、阈值、效用权重 |
| 结构 | 节点增删、子树排列 |
| 策略切换 | 何时重规划、何时用哪棵子树 |
| 叶子策略 | 叶子内部用 RL / 扩散策略，树负责编排 |

### 3. 进化与程序合成
- 遗传编程生成 BT
- 从演示归纳树结构
- 约束：安全节点不可删、必须含急停监视

### 4. 强化学习与 BT
- 选项（Options）/ 分层 RL 与 BT 子树对应
- 树结构固定、学叶子或学选择策略
- 奖励稀疏时，BT 提供骨架缓解探索

### 5. LLM 集成的几种深度
1. **生成**：自然语言 → BT XML/JSON
2. **修复**：失败日志 → 建议改树
3. **在线**：LLM 只在决策点调用，日常仍 Tick BT
4. **解释**：把 Running 路径翻译成人话（运维友好）

风险：幻觉结构、漏安全分支、不稳定输出 → 需要 schema 校验与仿真门禁。

### 6. 可解释性与认证
- 相对黑盒策略，BT 路径可审计
- 工业场景：安全互锁必须是硬节点，不能仅靠学出来的权重
- 人机信任：显示“当前目标 / 当前节点 / 打断原因”

### 7. 与机器人任务规划栏目的后续
- 本篇收束行为树线
- 后续可开：HTN/GOAP、任务与运动联合规划、TAMP 等平行系列
