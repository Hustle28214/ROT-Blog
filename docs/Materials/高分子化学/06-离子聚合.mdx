# 离子聚合

自由基对介质的宽容让它工业地位难以撼动，但**自由基做不到严格活性聚合、做不到精确的立构规整**。这些短板由离子聚合来补：

- **阳离子聚合**擅长带**给电子基团**的单体（异丁烯、乙烯基醚），可低温快速反应。
- **阴离子聚合**擅长带**吸电子基团**的单体（苯乙烯、丁二烯、丙烯腈、MMA），Szwarc 1956 年发现的**活性阴离子聚合**是所有活性聚合的原型。

两者共通点：**离子极其怕水、氧、二氧化碳**，实验和工业设备都要严格无水无氧。

## 1. 阴离子聚合

### 1.1 引发剂与单体

**引发剂**：碱金属（Na、K）、有机金属（$n$-BuLi）、碱金属萘负离子（Na$^+$·C$_{10}$H$_8^-$）、Grignard 试剂（部分）。

**单体活性顺序**（对阴离子）：丙烯腈 > 甲基丙烯酸甲酯 > 苯乙烯 ≈ 丁二烯 > 异戊二烯。**吸电子基使 $\beta$-碳的负电荷共振稳定**——阴离子聚合的电子学根源。

有机锂 $n$-BuLi 加成到苯乙烯：

$$
n\text{-BuLi} + \text{CH}_2=\text{CHPh} \longrightarrow n\text{-Bu-CH}_2-\text{CHPh}^-\text{Li}^+
$$

这个"活性种"是**碳阴离子-锂离子对**（ion pair），在非极性溶剂（苯、环己烷）中主要以缔合态（二聚、四聚）存在；在极性溶剂（THF、DME）中解离成自由离子和溶剂化紧密离子对。**溶剂极性影响活性种形态，进而影响立构规整性和速率**。

### 1.2 Szwarc 的活性阴离子聚合

**无终止、无链转移**——这是与自由基聚合最本质的差别。原因：

- 两个负离子链之间静电排斥，无法偶合。
- 没有 $\beta$-H 转移的合适路径（除非有强酸性 H）。
- 只要严格除去质子性杂质（水、醇、$\text{CO}_2$、$\text{O}_2$），链就一直"活着"。

活性种可以观察到：例如苯乙烯基锂在 THF 中呈鲜红色，只要没有终止剂就一直保持——加了 MMA 后颜色变浅（MMA 阴离子颜色不同）、活性依旧存在，这是嵌段能做的证据。

**分子量控制**：

$$
\overline{X}_n = \frac{[\text{M}]_0 - [\text{M}]}{[\text{I}]_0} \cdot (\text{每个引发剂产生的链数})
$$

以 $n$-BuLi 引发苯乙烯（单负离子端），$\overline{X}_n = [\text{M}]_0/[\text{I}]_0 \times$ 转化率。以萘钠引发（双阴离子中间产物，两端增长），乘 2。

**分子量分布**：所有链**同时开始、同速增长**——Poisson 分布，

$$
\overline{X}_w/\overline{X}_n = 1 + 1/\overline{X}_n \to 1
$$

分子量几百以上时 PDI 已接近 1.05，是所有聚合方法中最窄的。

### 1.3 嵌段共聚

活性阴离子的核心应用：**先聚 A，等 A 单体耗尽，加 B 单体继续**。就得到 A-B 嵌段。这样做 SBS 三嵌段（苯乙烯-丁二烯-苯乙烯，是热塑性弹性体 TPE 的原型）：

1. 环己烷 + $sec$-BuLi，加苯乙烯 → 聚苯乙烯基锂（S-Li）。
2. 加丁二烯 → S-B-Li。
3. 加二氯亚砜或 phosgene 之类的偶合剂 → S-B-S。

或者用双阴离子引发（$\alpha$-甲基苯乙烯钾萘）从中间双向增长：$B \to B-S \to S-B-S$。

**SBS 的两端聚苯乙烯段室温下是玻璃态微区（$T_g > $ 室温），中间的聚丁二烯段是橡胶态（$T_g < -60$ °C），微区提供物理交联，加热到 100 °C 以上就能像热塑一样加工**——不用硫化。这类"物理交联替代化学交联"的思路正是嵌段共聚给弹性体材料学的贡献。

### 1.4 立构规整性

阴离子聚合可以给出**较高等规**（isotactic）或间规（syndiotactic）比例，取决于溶剂和抗衡离子。以 MMA 阴离子聚合为例：

- 甲苯 + $n$-BuLi，$-78$ °C：等规度可达 90%。
- THF + $n$-BuLi，$-78$ °C：主要间规（60%）。

原因：非极性溶剂中紧密离子对，抗衡离子（Li$^+$）参与末端的空间约束，使新单体以固定取向加入。极性溶剂中离子对松散，无空间偏好。

### 1.5 阴离子聚合的工业地位

- **SBS/SIS 热塑性弹性体**（Kraton 系列）
- **含氟弹性体**（部分）
- **锂系溶聚丁苯**（S-SBR）：轮胎胎面胶主流，滚动阻力低。
- **聚苯乙烯的窄分布标样**、聚甲基丙烯酸甲酯特种。

这些产品体量比乳聚 SBR 小，但**结构可控性**是其他方法达不到的。

## 2. 阳离子聚合

### 2.1 引发剂与单体

**引发剂**：Lewis 酸（$\text{AlCl}_3, \text{BF}_3, \text{SnCl}_4$）+ 共引发剂（水、HCl）。共引发剂产生真正的引发种 $\text{H}^+$ 或阳碳离子。

$$
\text{BF}_3 + \text{H}_2\text{O} \rightleftharpoons \text{H}^+ [\text{BF}_3\text{OH}]^-
$$

**单体活性顺序**（对阳离子）：乙烯基醚 > 异丁烯 > 苯乙烯 > 丁二烯 ≫ 丙烯腈、MMA。**给电子基使 $\beta$-碳的正电荷共振稳定**。

### 2.2 反应特点

阳离子聚合的**速率极快**（低温下秒内完成）、**分子量对温度极其敏感**（升温分子量急剧下降）。工业丁基橡胶（异丁烯 + 少量异戊二烯）在 $-100$ °C 下 $\text{AlCl}_3/\text{CH}_3\text{Cl}$ 体系中反应。低温有两个原因：

1. 抑制链转移和终止（这两个反应的活化能高于增长）。
2. 抑制副反应（Friedel-Crafts 类）。

**主要的终止/链转移**：

- $\beta$-H 消除：$-\text{CH}_2\text{-C}^+\text{HR} \to -\text{CH}=\text{CHR} + \text{H}^+$，产生新的引发种，属链转移。
- 抗衡离子加成：氯化物阴离子加到阳碳离子上封端。
- 单体链转移：$\text{M}^+ + \text{M} \to \text{polymer} + \text{H}^+$——最难避免的。

由于这些机制，**传统阳离子聚合分子量分布宽（PDI 3–5），非活性**。

### 2.3 活性阳离子聚合

1984 年 Higashimura 和 Sawamoto 用 $\text{HI}/\text{I}_2$ 体系做异丁基乙烯基醚：$\text{HI}$ 加成给出 $-\text{CHI-CHR}$，$\text{I}_2$ 与末端形成 $-\text{CHI}\cdot\text{I}_2 \cdots$ 结构，处于活性和休眠间的动态平衡，**避免了 $\beta$-H 消除**。这是**第一个活性阳离子聚合**。

后来 Kennedy、Faust 等开发了 TMPCl（叔甲基氯）/$\text{BCl}_3$ 或 TiCl$_4$ 体系做异丁烯活性阳离子聚合，可以做 PIB-PS 嵌段。工业化的例子有粘度指数改进剂 OCP、含氨基端异丁烯低聚物。

### 2.4 阳离子聚合的立构规整

温度对立构规整影响很大：$-70$ °C 以下的乙烯基醚可以做出接近 100% 等规聚乙烯基醚（PIVE）。工业上不追求这一特性，但学术上是研究立构选择性机理的经典体系。

## 3. 阴离子 vs 阳离子

| | 阴离子 | 阳离子 |
|---|---|---|
| 引发种 | 碳负离子（有机金属） | 碳正离子（Lewis 酸 + 共引发） |
| 适宜单体 | 吸电子取代 | 给电子取代 |
| 反应温度 | 常规 $-80$ 至室温 | 通常 $-100$ 至 $-30$ °C |
| 速率 | 中至快 | 极快 |
| 链转移/终止 | 严格无水无氧下可几乎为零 | 天然易发生 |
| 分子量分布 | Poisson，PDI $\sim$ 1 | 传统宽（3–5），活性可窄 |
| 嵌段共聚 | 天然适用 | 需要活性体系 |
| 立构选择 | 溶剂/温度调控 | 温度显著影响 |
| 典型产品 | SBS、S-SBR | 丁基橡胶、聚乙烯基醚 |

## 4. 与自由基的对比总结

三种链聚合活性种，各有生态位：

- **自由基**：单体范围最广，工艺最粗放，产量最大。产品：塑料大宗、乳液涂料、SBR 乳聚版。
- **阴离子**：需活性种精确控制、单体窄。产品：嵌段共聚、窄分布特种、S-SBR。
- **阳离子**：低温快反应、单体窄。产品：丁基橡胶、聚异丁烯基油。

**离子聚合的活性种寿命长**这一点，是它能做嵌段和精确控制分子量的物理原因；但也是它对杂质敏感的原因——正因为寿命长，一个微量水分子就足以让链在合适时刻死亡。

下一章的**配位聚合**用过渡金属或稀土金属络合物作活性中心，兼顾**活性、立构选择、宽单体范围**——是聚烯烃工业的核心。
