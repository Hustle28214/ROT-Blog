# GR-1：释放视频生成预训练用于机器人操作

论文：[Unleashing Large-Scale Video Generative Pre-training for Visual Robot Manipulation](https://arxiv.org/abs/2312.13139)（Wu 等，ICLR 2024）。GR-1 的核心命题是：**机器人操作数据稀缺，但互联网上有海量人类操作视频——如果在这些视频上做视频预测预训练，能否把物理世界知识迁移到机器人控制？** 答案是肯定的，而且效果显著：在 CALVIN 跨场景泛化基准上，GR-1 的平均完成链长达到 3.06（vs 最佳基线 0.93），提升幅度约 **+229%**。

## 1. 核心洞察

机器人操作数据的规模通常只有数百到数千条轨迹，而 Ego4D 这类第一视角人类操作视频数据集有超过 3500 小时的内容，展示了手与物体交互的物理规律、空间关系、力的作用方式。

GR-1 的假设：**视频生成预训练能够编码丰富的物理世界先验**，迁移到机器人控制不需要改变架构，只需要一个统一的 Transformer——预训练阶段预测未来帧，微调阶段在同一套权重上加动作输出头。

## 2. 架构（GPT 风格因果 Transformer）

| 规格 | 值 |
|---|---|
| Transformer 层数 | 12 |
| 注意力头数 | 12 |
| 隐藏维度 | 384 |
| 总参数量 | **195M** |
| 可训练参数 | **46M**（编码器冻结）|

**输入模块：**
- 语言编码器：冻结的 **CLIP 文本编码器**
- 视觉编码器：冻结的 **MAE 预训练 ViT**（Masked Autoencoder）
- **Perceiver Resampler**：压缩 ViT 输出的 Patch token 数量，减少序列长度
- 输入序列：语言 token + 历史观测帧 token + 历史机器人状态

**双任务输出头（共享 Transformer 骨干）：**

1. **机器人动作头（3 层 MLP）：**
   - 手臂动作：Smooth-L1 损失
   - 夹爪开合：二元交叉熵损失

2. **视频预测解码器（Transformer 解码器 + 线性层）：**
   - 预测未来帧的图像 Patch 特征（MAE 特征空间，非原始像素）
   - MSE 损失

**联合损失：**

$$\mathcal{L} = \mathcal{L}_{\text{arm}} + \mathcal{L}_{\text{gripper}} + \mathcal{L}_{\text{video}}$$

微调阶段保留视频预测损失，防止灾难性遗忘。

## 3. 视频预训练

**数据：** Ego4D，超过 **3500 小时**第一视角人类操作视频，预处理为 3 秒片段 → **约 80 万片段，约 800 万帧**。每个片段配有自然语言描述。

**预训练目标：** 给定语言描述和历史帧，预测未来第 $t+\Delta t$ 帧：

$$\mathcal{L}_{\text{pretrain}} = \text{MSE}(\hat{F}_{t+\Delta t},\ F_{t+\Delta t})$$

预测在 **MAE 特征空间**中进行（而非原始像素），这是关键设计——MAE 特征比像素更语义化，预测更容易学，迁移到机器人控制的表征质量更高。预训练阶段没有机器人动作监督信号。

## 4. 微调

解冻 46M 可训练参数（Perceiver Resampler + Transformer 骨干 + 动作头），冻结 CLIP 和 MAE 编码器权重。批大小 512，AdamW，余弦衰减，20 epoch，预测步距 $\Delta t = 3$（机器人数据帧率更密）。

## 5. 实验结果

CALVIN 是最严格的多任务语言条件机器人操作基准：机器人需在一次运行中完成 1–5 个连续不同任务，评估各阶段完成率和**平均完成链长（Avg.Len）**。

**ABCD→D（全数据，域内测试）：**

| 方法 | 任务1 | 任务5 | **Avg.Len** |
|---|---|---|---|
| RT-1 | 0.844 | 0.227 | 2.45 |
| HULC | 0.889 | 0.383 | 3.06 |
| **GR-1** | **0.949** | **0.731** | **4.21** |

**ABC→D（零样本跨场景泛化）：**

| 方法 | 任务1 | 任务5 | **Avg.Len** |
|---|---|---|---|
| RT-1 | 0.533 | 0.013 | 0.90 |
| HULC | 0.418 | 0.011 | 0.67 |
| MT-R3M | 0.529 | 0.018 | 0.93 |
| **GR-1** | **0.854** | **0.401** | **3.06** |

零样本场景泛化 Avg.Len 从最佳基线 0.93 跳到 **3.06**，提升 **+229%**。

**仅 10% 训练数据：**

| 方法 | Avg.Len |
|---|---|
| HULC | 1.11 |
| **GR-1** | **2.00** |

低数据场景下 GR-1 的数据效率优势更明显——预训练的物理先验在数据稀缺时更有价值。

**真实机器人（多类物体）：**

| 评估类型 | RT-1 | **GR-1** |
|---|---|---|
| 已见物体 | 0.27 | **0.79** |
| 未见实例 | 0.13 | **0.73** |
| 未见类别 | 0.00 | **0.30** |
| 关节物体 | 0.35 | **0.75** |

**消融：预训练和视频预测的独立贡献（ABCD→D）：**

| 配置 | Avg.Len |
|---|---|
| 无预训练，无视频预测 | 3.33 |
| 有视频预测，无预训练 | 3.82 |
| **完整 GR-1** | **4.21** |

两者均有独立贡献，预训练的增益（+0.88）大于视频预测辅助任务（+0.49）。

## 6. 局限

Ego4D 是人手操作视频，与机器人夹爪外观有形态差距，迁移的边界尚未系统探索。预测在 MAE 特征空间中进行，物体被遮挡时预测器有时无法正确推理被遮挡物体的状态。GR-1 只在 CALVIN 单一平台评估，缺乏跨机器人平台的验证（不像 Octo 覆盖 9 个平台）。机器人数据规模仍远小于 Ego4D，论文指出扩大机器人轨迹规模是未来方向。

GR-1 的范式——在人类视频上做视频预测预训练，再微调到机器人动作——为后来 π0 系列用大规模机器人数据做预训练奠定了重要的思路基础，区别在于预训练数据是人类视频还是机器人数据。

代码见 [bytedance/GR-1](https://github.com/bytedance/GR-1)。
