# 导读：状态估计驱动的安全边界闭环

BMS 可以做成很大一张系统图：AFE、继电器、CAN、热管理、云平台、功能安全流程……  
若只允许保留一块**最关键、特有、且概念上最不交叉**的内核，它是：

> **把电池内部不可测状态估计出来，并转化为可执行的安全边界指令。**

更短一点：

- 只留一个词 → **状态估计**
- 只留一个闭环 → **状态估计驱动的安全边界控制**

本系列只写这条闭环。采集硬件、通信、RTOS、液冷硬件、云平台只作为接口 concisely 提及，不单独开篇。

## 1. 闭环长什么样

```text
电压 / 电流 / 温度 / 历史
        │
        ▼
   电池模型 + 估计器
        │
        ▼
 SOC / SOH / SOP / SOE / 内阻 / 内温 / 安全态
        │  （含不确定度 / 置信区间）
        ▼
 动态安全边界：限充 · 限放 · 降功率 · 均衡请求 · 切断/降级
        │
        ▼
     执行 → 改变工况 → 再测量
```

去掉通信、云、RTOS、液冷，系统仍可叫 BMS；  
去掉 SOC/SOH/SOP 与安全边界控制，它就退化成**保护板或数据采集板**。

## 2. 本系列目录（修订后）

初稿曾按“学科分册”拆成 14 段（电化学、耦合、UQ、MCU 各占一章）。多视角评议后的结论是：**过度拆分**——工业上它们同属一条交付链，博客连载也容易在薄章处弃坑。

定稿如下（约 8 篇主文 + 术语附录）：

| 编号 | 标题 | 读者应带走的东西 |

### 相对初稿，合并与降级了什么

| 原设想 | 处理 | 原因 |
|---|---|---|
| 电化学与老化专章 | → 并入 01 | “为模型服务的最小集”单独成章易注水 |

| 限功率/充放电/均衡决策专章 | → 限功率进 04；均衡进 05 | 避免与 SOP、Pack 三章抢素材 |

### 刻意后写 / 不写的

- 功能安全全流程、AUTOSAR、云平台、热管理硬件 → 接口级提及即可  
- 纯电化学材料学、PACK 机械结构 → 不在本系列范围  

## 3. 建议阅读与写作顺序

编号是逻辑顺序；**动手写时不必从 00 苦熬定义**：

1. **01 建模** — 后续全引用，资产最稳  
2. **02 SOC** — 系列主菜，续写动力最强  
3. **04 SOP / 限功率** — 证明 BMS 不是估计算法合集，而是边界决策  

电化学补丁、术语表、实现约束可以随写随补。

与站内已有笔记的接缝：

- [EKF / 机器人状态估计](/docs/Robotics/机器人学状态估计/IMU/EKF扩展卡尔曼滤波) → 复用滤波框架，重写电池过程模型与噪声  
- 控制直觉 → 把 SOP 看成**状态约束下的可行集投影**  
- 传感笔记 → 只保留测量噪声/偏置对估计协方差的影响  

## 4. 每篇固定模板

1. 要估计 / 要约束的量  
2. 模型假设与失效工况  
3. 算法或策略（公式级即可）  
4. 误差来源与保守策略  
5. 如何验证（真值、指标、工况）  
6. 接到边界控制的接口（输入 / 输出）  
7. 开放问题与文献入口
