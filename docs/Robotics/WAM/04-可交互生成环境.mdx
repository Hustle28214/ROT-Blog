# 可交互生成环境：从 IRIS 到 Genie

这条线的目标物跟前面两篇不一样。Dreamer、MuZero 学模型是为了训策略，模型本身不用给人看；这一支要的是一个人和智能体都能进去操作的生成式环境，说白了就是想用神经网络当游戏引擎。它对机器人的意义主要在数据侧：如果环境可以生成，训练数据的天花板就不再由真机采集决定。

## 1. IRIS：把观测离散成 token，再自回归

[IRIS](https://arxiv.org/abs/2209.00588)（2022）的结构很像语言模型。先用离散自编码器把每帧图像编成 $K$ 个 token，然后用一个 Transformer 在 token 序列上自回归地预测下一帧、奖励和终止信号：

$$
p_\theta(x_{t+1}^{1:K}, r_t, d_t \mid x_{\le t}^{1:K}, a_{\le t})
$$

策略完全在这个想象出来的 token 世界里用 actor-critic 训练。在 Atari 100k（只允许两小时游戏经验）上，它是当时少数几个超过人类平均分的方法。

离散 token 的好处是可以直接套成熟的自回归框架，坏处是量化误差会以块状伪影的形式出现，而且这些伪影会被策略当成真实特征去利用。

## 2. DIAMOND：换成扩散，保住细节

[DIAMOND](https://arxiv.org/abs/2405.12399)（2024）把世界模型换成扩散模型，直接在像素空间做动作条件的下一帧生成，不再经过离散量化。它的论点是：Atari 里很多决定性的细节（子弹、小敌人）在离散 token 化之后就丢了，而策略恰恰要靠这些细节。

同样的 100k 预算下它拿到了更好的成绩，视觉上也明显更干净。代价是采样贵，所以它把扩散步数压到很少的几步，并且用 EDM 那套参数化来保证少步数下仍然稳定。

这两篇放一起看很有意思：同一个任务、同一个数据预算，唯一的变量是世界模型的生成方式，结论是保真度确实会转化成策略性能。这个结论在机器人上还没被同样干净地验证过。

## 3. Genie：从没有动作标签的视频里学出可控性

[Genie](https://arxiv.org/abs/2402.15391)（2024）解决的是这条线最大的瓶颈：互联网视频没有动作标签。它的做法是让模型自己发明动作。

三个部件：

- 视频 tokenizer，把帧压成离散 token；
- latent action model，用一个 VQ 瓶颈从相邻两帧里推出一个离散的 latent action，词表非常小（8 个）；
- 动力学模型，给定历史 token 和 latent action 预测下一帧 token。

训练时 latent action 由前后帧推出来，推理时换成人给的离散输入。瓶颈开得这么窄是刻意的：容量一大，latent action 就会把整帧的内容都编进去，动力学模型退化成直接抄答案，可控性就没了。这个"信息瓶颈换可控性"的设计我觉得是整篇最漂亮的地方。

11B 参数，20 万小时互联网游戏视频，出来的效果是可以拿一张没见过的图片（照片、手绘草图都行）当初始帧，然后用统一的离散动作去操作它。

[Genie 2](https://deepmind.google/discover/blog/genie-2-a-large-scale-foundation-world-model/)（2024）把它推进到能从单张图生成可操作的 3D 风格环境；[Genie 3](https://deepmind.google/discover/blog/genie-3-a-new-frontier-for-world-models/)（2025）做到 720p、24 FPS 和分钟级的一致性。这两个只有博客没有论文，细节不明。

## 4. 评测上要小心的地方

这条线的 demo 特别有说服力，也特别容易过度解读。我自己会分开看这几件事：

1. 可控性。同一个初始帧给不同动作，输出是不是真的不同？很多模型只是沿着数据里常见的运动外推，动作输入的边际影响很小。
2. 物体永久性。物体移出视野再回来，还是原来那个吗？这个直接决定能不能用来训需要记忆的策略。
3. 长时一致性。滚十几秒之后几何、光照、目标状态有没有漂。视频看着合理和几十秒后仍然自洽是两件事。
4. 物理是否守恒。质量、接触、支撑关系有没有被违反。生成模型很擅长画出物理上不可能但视觉上顺眼的画面。

放到 [WAM](./00-世界模型的起点与前沿.mdx) 的语境里，这条线提供的是数据和环境，不直接提供策略。真正把生成模型接到动作上的是 [DiT4DiT](./06-DiT4DiT.mdx) 和 [MotionWAM](./01-MotionWAM.mdx) 那一路，而它们的做法反过来也说明了一件事：为了实时，最后并没有真的去生成视频。
