> **L6 运行时架构层**（进阶）：tick 频率、时间片、异步节点、确定性与多机同步。

## 大纲

### 1. 调度模型
- 固定频率 tick（如 10–50Hz）
- 事件触发 tick（话题、定时器、外部请求）
- 混合：心跳 + 紧急事件立即 tick
- 与底层控制环解耦：决策慢、控制快

### 2. 时间片与长叶子
- 单 tick 预算：超时则拆步或返回 Running
- 禁止在叶子里 `sleep` 阻塞整树
- 大计算放到后台，结果回写黑板

### 3. 异步节点
- 启动异步工作 → Running → 轮询完成 / 回调置位
- 取消：必须能 halt 异步任务
- Future/Promise、ROS Action、线程池的封装模式

### 4. 多线程与线程安全
- 常见架构：BT 单线程；感知/控制多线程写黑板
- 黑板锁粒度、无锁环形缓冲、双缓冲快照
- 切忌：多线程同时 Tick 同一棵树（除非框架明确支持）

### 5. 确定性
- 相同输入 → 相同决策轨迹（仿真复现、CI）
- 时间源、随机数、异步完成顺序都会破坏确定性
- 策略：逻辑时钟、可记录的事件队列、禁用不稳定并行

### 6. 多机器人 / 网络同步（点到为止）
- 各机本地 BT + 共享任务黑板（协调层）
- 延迟、丢包下的“意图同步”而非“逐 tick 同步”
- 详细网络协议留给专题；本篇只给架构边界

### 7. 推荐默认架构（机器人）
```text
感知线程 → 黑板快照
    ↓
决策线程：Tree.Tick() @ N Hz
    ↓
命令队列 → 控制线程
```
