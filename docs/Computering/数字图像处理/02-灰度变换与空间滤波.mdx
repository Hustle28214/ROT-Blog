# 灰度变换与空间滤波：在像素邻域里做事

数字图像处理里，"变换"这个词有两种截然不同的含义。一种是本章的**空间域**处理——直接对像素值 $f(x,y)$ 做函数变换 $g(x,y)=T[f(x,y)]$；另一种是下一章的**频率域**处理，要先把图像搬到 Fourier 空间。空间域简单粗暴，物理意义直观，绝大多数经典操作（点运算、模板卷积、直方图均衡）都属于这一类。

## 1. 灰度变换的三种基本形态

灰度变换只看单个像素，不看邻居。最一般的形式是 $s=T(r)$，$r$ 是输入灰度值，$s$ 是输出灰度值。曲线的形状决定了做什么。

**图像反转**：$s=L-1-r$。适合把暗图像里的白色小细节反出来，比如医学乳腺 X 光片背景是黑的，肿块反转后更容易被眼睛抓住。

**对数变换**：$s=c\log(1+r)$。把小值域展开、大值域压缩，常用来看 Fourier 频谱——频谱的直流分量可能比高频分量大几个数量级，直接线性显示只能看到一个亮点，取对数以后细节才显出来。

**幂律（伽马）变换**：$s=cr^\gamma$。$\gamma<1$ 时把暗部展开（提亮暗处），$\gamma>1$ 把亮部展开。CRT 显示器天然有 $\gamma\approx 2.5$ 的响应曲线，图像编码时预先做 $\gamma=1/2.5$ 的补偿，这就是 sRGB 里那个奇怪的伽马校正的由来。

**分段线性变换**：想在某个灰度区间拉伸、在其他区间压缩，只需要画一条折线。比灰度切片、位平面切片都是这个思路的特化形式。

三类曲线放在一起看：

```
    输出 s
    │        ┌─ 幂律 γ<1 (提亮)
  L-1 ─┐    ╱
      │╲  ╱ ── 对数
      │ ╲╱
      │ ╱╲
      │╱  ╲ ── 幂律 γ>1 (压暗)
    0 ┴────────── 输入 r
      0        L-1
```

## 2. 直方图：图像的一维统计签名

直方图是 $h(r_k)=n_k$，第 $k$ 个灰度级出现了多少次。归一化后 $p(r_k)=n_k/MN$ 就是这个灰度值的概率。整幅图像被压缩成一个 256 维向量，几何信息全丢了，但**亮度分布和对比度**保留下来。

直方图能干几件事：

- **判断曝光**：直方图挤在左边说明欠曝，挤在右边过曝，中间瘦条带说明对比度不足
- **判断双峰**：两个明显的峰意味着前景/背景分离良好，[图像分割](./09-图像分割.mdx)里 Otsu 阈值就是找这两个峰之间的谷
- **匹配**：把一幅图的直方图变换成另一幅的样子，做风格迁移的雏形

### 2.1 直方图均衡

想让直方图变均匀（每个灰度级都有相同的像素数）。变换函数是累积分布函数：

$$
s_k = T(r_k) = (L-1)\sum_{j=0}^{k} p_r(r_j)
$$

这个 $T$ 是**单调非减**且值域覆盖 $[0, L-1]$ 的——单调保证不改变灰度顺序，覆盖保证利用满动态范围。数学证明：如果连续变量 $r$ 有任意分布 $p_r(r)$，用 $s=(L-1)\int_0^r p_r(w)dw$ 变换后 $p_s(s)$ 一定是均匀分布。离散情况下由于灰度级有限，只能近似均匀。

均衡是全自动的、无参数的。参数是好事也是坏事——不需要调参说明它没有主观偏好，但也不能针对特定任务定制。所以有了下面的**规定化**。

### 2.2 直方图规定化（匹配）

想让输出直方图匹配一个指定分布 $p_z(z)$ 而不是均匀分布。做法是：

1. 对输入求均衡变换 $s=T(r)$
2. 对目标分布求均衡变换 $v=G(z)$
3. 由于都变到了均匀分布，$s=v$，反过来 $z=G^{-1}(s)=G^{-1}(T(r))$

一个用途是把夜景照片的直方图匹配到白天的，做假的白天效果。另一个用途是做多幅图像的亮度归一化——医学、遥感里常见，让不同时间不同曝光条件下的图像可比。

### 2.3 局部直方图处理

全局均衡的问题是它把整幅图当一个整体统计。如果图像里既有阳光下的高反差区域，也有阴影下的低反差区域，全局均衡会牺牲一方成全另一方。**局部直方图均衡**在每个像素周围开一个 $n\times n$ 邻域，只用邻域内的直方图算变换，只更新中心像素。计算量大，但可以让阴影里的细节和高光里的细节同时显现。

CLAHE（Contrast Limited Adaptive Histogram Equalization）是这个思路的工程版本：分块做均衡，块间双线性插值防止分界线，直方图先裁剪防止过增强噪声。医学影像和 OpenCV 里都是默认工具。

## 3. 空间滤波：从点运算到邻域运算

前面所有的操作都是**点运算**——输出像素只依赖同位置的输入像素。空间滤波开始考虑邻居。一个 $m\times n$ 的模板 $w$ 在图像上滑动，中心位置 $(x,y)$ 的输出是：

$$
g(x,y)=\sum_{s=-a}^{a}\sum_{t=-b}^{b} w(s,t)\, f(x+s,y+t)
$$

这个式子是**相关**（correlation）。翻转模板后再算就是**卷积**（convolution）：

$$
g(x,y)=\sum_{s=-a}^{a}\sum_{t=-b}^{b} w(s,t)\, f(x-s,y-t)
$$

数学上卷积满足交换律、结合律、分配律，深度学习里所谓的"卷积层"实际上做的是相关（PyTorch/TF 都是），但因为核是学出来的，翻转不翻转无所谓。经典 DIP 严格区分这两者，因为用手工设计的核（比如 Sobel）时翻转会改变梯度符号。

## 4. 平滑滤波：把噪声抹掉

### 4.1 均值滤波

模板全部填 $1/(mn)$。$3\times 3$ 均值核：

```
1/9 1/9 1/9
1/9 1/9 1/9
1/9 1/9 1/9
```

线性、简单、把高斯噪声压下去，代价是边缘也被模糊了。噪声方差降到 $\sigma^2/n$（$n$ 是核内像素数），但边缘处的锐利过渡也变成了 $n$ 像素宽的过渡带。

**加权均值**（高斯核）把权重按距离衰减，边缘保得稍好，但仍然是线性滤波器，处理不了椒盐噪声。

### 4.2 中值滤波

模板内 $mn$ 个像素排序取中值。非线性，无法用卷积表达，也没有频域解释。但它对**椒盐噪声**（极端离群点）极其有效——一个孤立的白点周围全是暗点，排序后中值一定是暗的。

代价：细结构会被抹掉。宽度小于模板一半的细线会消失。所以医学血管、指纹图像用中值要小心。

### 4.3 双边滤波

均值滤波按空间距离加权，双边滤波额外按**灰度值差异**加权：

$$
g(x,y)=\frac{1}{W}\sum_{s,t} f(x+s,y+t)\, e^{-\frac{s^2+t^2}{2\sigma_d^2}}\, e^{-\frac{(f(x+s,y+t)-f(x,y))^2}{2\sigma_r^2}}
$$

灰度差异大的邻居权重接近 0，等于自动跳过边缘另一侧的像素。这是"保边平滑"的经典做法。$\sigma_d$ 控制空间平滑范围，$\sigma_r$ 控制灰度容忍度。

后来的 Guided Filter、非局部均值 NLM 都是这个思路的推广。深度学习时代 U-Net 之类的去噪网络本质上也在学"哪个邻居该信任"。

## 5. 锐化滤波：把边缘凸出来

平滑是求平均（积分），锐化是求差分（微分）。一阶差分响应阶跃，二阶差分响应双边——一正一负——所以对细节更敏感。

### 5.1 拉普拉斯算子

二阶各向同性微分算子：

$$
\nabla^2 f = \frac{\partial^2 f}{\partial x^2}+\frac{\partial^2 f}{\partial y^2}
$$

离散形式的模板是：

```
 0  1  0        1  1  1
 1 -4  1   或   1 -8  1  (含对角)
 0  1  0        1  1  1
```

用法：$g(x,y)=f(x,y)+c\,\nabla^2 f(x,y)$，$c$ 的符号取决于模板中心是正还是负。物理上 $\nabla^2 f$ 在边缘处是双极响应（一正一负紧挨着），叠加回原图会让边缘两侧的对比度加大，视觉上更"清晰"。

### 5.2 反锐化掩蔽和高提升滤波

先对图像做低通滤波得到 $\bar f$，模板（mask）$g_{\text{mask}}=f-\bar f$ 就是高频部分，然后加权加回去：

$$
g(x,y)=f(x,y)+k\cdot g_{\text{mask}}(x,y)
$$

$k=1$ 是标准反锐化掩蔽，$k>1$ 是高提升。相机里"锐化强度"滑块调的就是 $k$。

### 5.3 Sobel 算子和梯度

一阶梯度：

$$
\nabla f=\begin{bmatrix}g_x\\g_y\end{bmatrix}=\begin{bmatrix}\partial f/\partial x\\\partial f/\partial y\end{bmatrix}
$$

幅值 $M(x,y)=\sqrt{g_x^2+g_y^2}$，方向 $\alpha(x,y)=\arctan(g_y/g_x)$。Sobel 模板：

```
Gx:                Gy:
-1  0  1          -1 -2 -1
-2  0  2           0  0  0
-1  0  1           1  2  1
```

比 Prewitt（权重全 1）多了个"中心行/列权重加倍"，这个加权来自于对高斯的一阶差分近似——理论上更抗噪。Sobel 后来成了 Canny 边缘检测的第一步。

## 6. 混合空间滤波

真实工程里几乎不会只用一个滤波器，而是把多个链在一起。Gonzalez 教材里的经典例子：

1. 原图（骨扫描）：对比度差、噪声大
2. 拉普拉斯锐化 → 加强边缘
3. Sobel 幅值 → 得到梯度图
4. Sobel 图做 $5\times 5$ 均值 → 平滑掉细节梯度、保留大结构
5. 用（4）作为 mask 乘上（2）→ 只在大结构处保留锐化效果
6. 结果与原图相加 → 恢复整体亮度
7. 幂律 $\gamma=0.5$ → 提亮暗部

7 步操作，每一步都是本章的基本工具。这个流水线的意义在于：**线性组合和非线性变换交错**，前者调整强度，后者调整选择性。这也是"数字图像处理"作为一门工程学科的典型面貌——不追求单个算法完美，而是流水线整体可用。

## 7. 边界处理

模板贴到图像边缘时，一部分邻居坐标超出图像范围。处理方式有几种：

| 方式 | 做法 | 副作用 |
|---|---|---|
| 零填充 | 越界值填 0 | 边缘会变暗 |
| 复制填充 | 越界值等于最近的边界像素 | 边缘方向被复制 |
| 镜像 | 关于边界翻折 | 常用，工件最小 |
| 循环 | 用另一侧的像素 | 假设图像周期，Fourier 域天然如此 |
| 有效模式 | 输出比输入小 $(m-1)\times(n-1)$ | 尺寸不一致 |

深度学习里 padding='same' 一般是零填充，训练时网络会学着补偿边缘偏差。经典 DIP 更常用镜像。

## 8. 空间域和频率域的关系

本章的所有滤波器都可以用[频率域](./03-频率域滤波.mdx)理解——空间域卷积等价于频率域乘法（卷积定理）。均值滤波对应低通、拉普拉斯对应高通、双边滤波在频率域没有简洁表达（非线性）。

为什么空间域还值得学？

- 小模板（$3\times 3$、$5\times 5$）在空间域计算比 FFT 快
- 非线性滤波器只能在空间域实现
- 直观：知道每个权重意味着什么

大模板（比如 $65\times 65$ 高斯）就该去频率域。经验界限大约在核尺寸 $\geq 15$ 时 FFT 划算。
