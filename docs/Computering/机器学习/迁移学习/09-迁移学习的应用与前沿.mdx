## 1. 迁移学习的典型应用

《迁移学习导论》第二版中，作者用整章篇幅介绍了迁移学习在真实世界的落地。以下是最有代表性的几个方向。

### 1.1 计算机视觉

- **图像分类跨域** ：Office-31、Office-Home、DomainNet 等基准，模拟不同风格（自然照片 / 艺术画 / 素描）的迁移。
- **目标检测与分割** ：从合成数据（GTA V、SYNTHIA）迁移到真实城市街景（Cityscapes、KITTI），已成为自动驾驶感知的标准做法。
- **医疗影像** ：不同医院、不同厂商的 CT/MRI 成像差异极大，迁移学习是医学 AI 落地的必备工具。
- **人脸识别** ：跨种族、跨光照、跨设备的迁移。
- **视频行为识别** ：从公开数据集迁移到监控视频的场景。

### 1.2 自然语言处理

- **预训练语言模型（PLM）** ：BERT、GPT、T5 等大规模预训练本质上就是一种大规模迁移学习。
- **跨语言迁移** ：高资源语言（英语） → 低资源语言（藏语、维语）的模型迁移。
- **跨领域情感分析** ：Amazon 商品评论中"图书"域 → "电子产品"域的迁移。
- **命名实体识别（NER）** ：新闻语料 → 医学/法律语料。

### 1.3 语音与音频

- **跨说话人语音识别** ：预训练模型 + 少样本说话人自适应；
- **跨语种 TTS** ：迁移一门语言的合成能力到另一门语言；
- **音频分类** ：从大规模 AudioSet 预训练迁移到特定音效识别。

### 1.4 推荐系统

- **跨域推荐** ：电影 → 图书、电商 → 短视频，将用户偏好从一个域迁移到另一个域；
- **冷启动** ：新用户/新物品几乎无历史数据，靠跨域迁移或群体先验；
- **联邦迁移** ：不同企业间数据不可共享，通过联邦学习 + 迁移学习协同建模。

### 1.5 时间序列与信号处理

- **人体行为识别（HAR）** ：跨用户、跨设备、跨传感器位置；
- **故障诊断** ：不同工况下的设备故障迁移；
- **脑机接口（BCI）** ：不同被试者之间迁移，减少标定成本。

### 1.6 强化学习

- **Sim-to-Real** ：仿真环境 → 真实机器人，是机器人 RL 落地的关键；
- **策略迁移** ：一个任务上的策略迁移到相似任务；
- **世界模型迁移** ：跨任务共享环境模型。

## 2. 大模型时代的迁移学习

近年最激动人心的变化是：**大模型本身就是迁移学习** 。

### 2.1 预训练—微调范式

BERT、GPT、CLIP、ViT、LLaMA、Diffusion 模型……几乎所有当代主流模型都遵循"大规模预训练 → 下游任务适配"的模式。它们把"表示学习"这一步做到极致，然后通过多种"轻量适配"方式迁移到具体任务。

### 2.2 参数高效微调（PEFT）

对超大模型，全参微调过于昂贵。业界发展出一系列参数高效方法：

- **Adapter** ：在每层插入小 MLP，训练时只更新 Adapter 参数；
- **LoRA / QLoRA** ：把权重更新分解为低秩矩阵，只训练低秩因子；
- **Prefix / Prompt Tuning** ：只训练少量"虚拟 token"；
- **BitFit** ：只微调偏置项。

这些都可以看作是"深度迁移"的现代变体，用极小代价完成模型迁移。

### 2.3 In-context Learning 与 Zero/Few-shot

GPT 系列展示了一种全新的"迁移"方式：**根本不更新参数** ，只在推理时给几个示例，让模型自行完成任务泛化。这背后其实是"预训练里已经隐含了任务分布"这一观点。

### 2.4 基础模型与领域泛化

CLIP、DINOv2、SAM 等基础模型天然具备强跨域泛化能力，很多传统 DA/DG 基准在这些模型上被"轻松刷爆"。这提醒我们：随着预训练规模增大，很多传统迁移问题会被"稀释"，但小样本、专业领域仍留有大量迁移研究空间。

## 3. 安全与可信迁移

### 3.1 联邦迁移学习

在数据无法离开本地（如医疗、金融）的场景下，将迁移学习与联邦学习结合：

- 模型参数或梯度在服务器上聚合；
- 各方通过迁移学习共享表示知识；
- 保护隐私 + 提升小机构模型效果。

### 3.2 隐私保护

- **差分隐私 + 迁移学习** ：在训练/迁移过程中引入噪声，保证个体样本无法被反推；
- **同态加密 + 迁移** ：在密文空间完成迁移训练，代价高但保密性极强。

### 3.3 鲁棒迁移

对抗样本、后门攻击可能污染预训练模型，进而"迁移"到下游任务。研究方向包括：

- 检测预训练权重的后门；
- 训练鲁棒适配器；
- 在迁移中同时优化鲁棒性目标。

## 4. 前沿方向

### 4.1 因果迁移学习

从统计相关性走向因果，寻找真正跨域不变的机制。相关工作：IRM、REx、Invariant Causal Prediction。

### 4.2 终身学习与持续迁移

模型需要在不遗忘旧知识的前提下不断吸收新任务的知识：

- **EWC** 、 **SI** 等基于权重正则；
- **回放** 、 **生成回放** 等基于样本存储；
- **动态架构** 、 **PackNet** 等按任务分配子网络。

### 4.3 提示学习（Prompt Learning）

不改变主干参数，通过设计输入端的提示 / 软 prompt 完成任务迁移。CoOp、CoCoOp、VPT 等把这一思想引入视觉领域。

### 4.4 多模态迁移

CLIP、Flamingo、BLIP、GPT-4V 等模型展现了跨模态知识迁移的巨大潜力：从文本到图像、从图像到文本、从多模态到具身智能。

### 4.5 具身智能与 Sim-to-Real

面向机器人与自动驾驶，将仿真中习得的策略迁移到物理世界。域随机化、系统辨识、可微仿真是主要技术路线。

## 5. 学习路线建议

如果你想系统入门迁移学习，建议：

1. **打好基础** ：掌握概率论、机器学习基础、深度学习基础；
2. **理解经典方法** ：TCA/JDA/CORAL/DANN 至少实现一次；
3. **紧跟深度迁移** ：DDC/DAN/JAN/DSAN 阅读并复现；
4. **走向前沿** ：DG / IRM / PEFT / Prompt / 大模型迁移；
5. **动手做项目** ：Office-Home、DomainNet、Wilds 上跑一遍完整实验；
6. **关注综述** ：Pan & Yang (2010)、Wang & Deng (2018)、Wang et al. (2022 DG survey)、Zhuang et al. (2020 comprehensive survey)。

## 7. 结语

迁移学习从最初的样本重加权、特征变换，走到了今天的深度对抗、领域泛化、大模型微调、参数高效适配。它已经不再是一个"技术点"，而是贯穿整个机器学习工程的 **底层思想** ：

> 让机器像人一样，把过去学到的东西用在新情境中。

在数据总是不够、场景总在变化的现实世界里，这一思想只会越来越重要。
