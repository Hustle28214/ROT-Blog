## 大纲

### 1. 节点注册与工厂
- 类型名 → 构造函数表
- 插件化：动态库加载自定义叶子
- 参数反射：编辑器与运行时同一套 schema

### 2. 资产格式与解析
- XML / JSON / YAML / 二进制
- 树引用子树、符号端口（输入输出）
- 版本兼容与迁移

### 3. “编译”指什么
- 解析后的对象图 → 可执行节点图
- 可选：扁平化、内联子树、预分配
- 端口连线解析成黑板键或局部存储偏移

### 4. 内存布局
- 节点池、减少每 tick 分配
- 字符串键 → 整数 ID 映射
- 托管语言注意 GC 尖峰；C++ 注意碎片与缓存友好

### 5. 生命周期
```text
load → create → activate → tick* → halt → deactivate → destroy
```
- 树切换、热重载时旧树如何 halt 干净
- 叶子持有的外部资源（client、句柄）归属

### 6. 黑板实现要点
- 类型擦除 vs 强类型端口
- 读写权限、调试 watch
- 线程安全策略与快照 API
- 事务式更新（一帧内一致性）

### 7. 可测试的内核
- 纯逻辑核心与中间件适配分离
- 录制/回放钩子打在 Tick 边界
- 断言：halt 后无悬挂异步

### 8. 可参考实现（阅读导向）
- BehaviorTree.CPP
- Unreal Behavior Tree
- 游戏 AI 常用开源 BT（作对照，注意与机器人差异）
