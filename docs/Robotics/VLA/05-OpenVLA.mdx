# OpenVLA：开源的视觉-语言-动作模型

论文：[OpenVLA: An Open-Source Vision-Language-Action Model](https://arxiv.org/abs/2406.09246)（Moo Jin Kim 等，2024）。OpenVLA 做的事很直接：把 RT-2 的核心思路（VLM 输出动作 token）用开源模型复现，然后在更大的开放机器人数据集上训练，结果 **7B 模型在未见任务上比 RT-2-X（55B）高出 16.5%**。

## 1. 架构：Prismatic-7B

OpenVLA 基于 **Prismatic-7B**——一个双编码器融合 VLM。

**视觉编码器（双路融合，约 600M 参数）：**
- **SigLIP**：高层语义理解，来自互联网规模对比学习
- **DINOv2**：低层空间特征，对操作任务的精确定位至关重要
- 融合方式：两路输出 patch 特征向量**逐通道拼接**（不是求平均，不是分别投影）
- 输入分辨率：224×224

双路融合直接针对 CLIP/SigLIP 单路编码器缺乏空间精度的问题。实验表明冻结视觉编码器会显著损害下游性能，所以预训练时视觉编码器也参与更新。

**语言主干：** Llama 2 7B，标准自回归解码器。

**投影器：** 2 层 MLP 将拼接后的视觉特征映射到 LLM 的 token 嵌入空间。

总参数约 **7.5B**。

## 2. 动作表示

和 RT-2 一样，OpenVLA 把连续动作离散化为词汇表 token：

- 每个动作维度划分为 **256 个区间**，边界取训练数据 **第1–99百分位**（避免异常值干扰）
- 将 Llama 2 词汇表中**使用频率最低的 256 个 token** 就地覆盖为动作 token（无需扩展词汇表）
- 推断时模型生成 7 个连续 token（6-DOF 机械臂 + 夹爪），反量化回连续动作
- 训练目标：**仅对动作 token 计算交叉熵损失**

## 3. 训练数据：Open X-Embodiment

**共约 97 万条机器人示范，来自 26+ 数据集**，从 Open X-Embodiment（OXE）合集精选。

主要数据源权重：

| 数据集 | 权重 |
|---|---|
| Bridge V1+V2 | 13.3% |
| Fractal（Google Robot） | 12.7% |
| Kuka | 12.7% |
| BC-Z | 7.5% |
| FMB | 7.1% |

覆盖平台：WidowX、Google 移动机械臂、Franka、Jaco、UR5、Kuka 等。

**训练规模：** 64× A100，14 天（约 21,500 A100·小时），批大小 2048，学习率 2e-5（固定，无预热），训练 27 epoch 直至动作 token 预测精度超过 95%。

## 4. LoRA 微调

OpenVLA 的一大贡献是证明 **LoRA 可以在单卡 A100 上高效微调**：

| 策略 | 成功率 | 可训练参数 | 显存 |
|---|---|---|---|
| 全量微调 | 69.7% | 7188M | 163 GB |
| **LoRA r=32** | **68.2%** | **97.6M** | **59.7 GB** |
| 仅最后一层 | 30.3% | 465M | 51 GB |
| 冻结视觉编码器 | 47.0% | 6760M | 156 GB |

LoRA r=32 以 1.4% 参数量取得与全量微调相当的效果。量化支持：bfloat16（16.8 GB，~6 Hz/RTX 4090）；int4（7 GB，~3 Hz）。

## 5. 实验结果

**vs. RT-2-X（55B）on BridgeData V2 + Google Robot（29 任务）：**
- OpenVLA 领先 **+16.5% 绝对成功率**
- Google Robot 任务两者相当；BridgeData V2 上 OpenVLA 明显领先

**vs. Diffusion Policy on Franka 7 任务微调：**
- OpenVLA 领先 **+20.4%**
- OpenVLA 是唯一在所有测试任务上均达到 ≥50% 成功率的方法

**模型对比：**

| 模型 | 参数 | 开源 | 可微调 | 机器人示范量 |
|---|---|---|---|---|
| RT-2-X | 55B | 否 | 否 | ~35万 |
| Octo | 93M | 是 | 是 | — |
| **OpenVLA** | **7B** | **是** | **是（LoRA）** | **97万** |

## 6. OpenVLA 与 RT-2 的核心差异

| 维度 | OpenVLA | RT-2-X |
|---|---|---|
| 开源 | 是（权重 + 代码） | 否 |
| 视觉编码器 | SigLIP + DINOv2 双路融合 | ViT-22B 单路 |
| 是否协同互联网数据训练 | 否 | 是 |
| 推断 | ~6 Hz（RTX 4090） | 云端 TPU，1–3 Hz |

RT-2 的优势是和互联网规模视觉-语言数据协同训练，保留了更广泛的语义基础。OpenVLA 牺牲了部分语义广度，换来了开放性、可微调性和更大的机器人数据集。

## 7. 局限

OpenVLA 仅支持单帧图像输入，没有多摄像头、本体感知历史或观测堆叠。6 Hz 的推断速度对需要 50 Hz 的 ALOHA 等高频系统太慢——论文把动作分块和推测解码留为了未来工作。

没有任务成功率超过 90%，尚未达到生产可用水平。关键设计轴（基础 VLM 规模、互联网数据协同训练效益）在论文中都没有系统探索，留下了很多开放问题供 [π0](./03-π0.mdx) 等后续工作回答。

代码和权重见 [openvla/openvla](https://github.com/openvla/openvla)。
