# 曲面细分与几何细分：把粗网格磨成光滑曲面

[NURBS](./参数曲线与曲面.mdx) 能画光滑曲面，但要求控制点排成整齐的四边形网格，任意拓扑（球、人脸、章鱼）就露怯了。**曲面细分**（subdivision surface）走了另一条路：从任意拓扑的粗网格出发，反复按规则细分并平滑，极限位置是一张光滑曲面。皮克斯《玩具总动员 2》之后几乎所有动画电影角色都是细分曲面建模，游戏引擎的 GPU 曲面细分着色器也在做同一件事——只不过实时罢了。

## 1. 细分的基本节奏

一个细分算法有两个动作交替进行：

1. **拓扑细分**：在原网格的边、面上插入新顶点，重新连边形成更密的网格
2. **几何平滑**：按某种加权平均，把新旧顶点位置更新一遍

每迭代一次面数大约 $\times 4$，$k$ 次后 $4^k$ 倍。极限曲面（limit surface）是 $k\to\infty$ 时的位置，理论上光滑（除个别"奇异点"外一般 $C^2$），实际渲染只需要迭代到看不出折线为止（通常 2-3 次）。

细分方案按目标网格类型分两大流派：

- **面向四边形网格**：Catmull-Clark（1978）
- **面向三角形网格**：Loop（1987）、Butterfly（插值型）、√3（2000）

按行为分：

- **近似型**（approximating）：极限曲面**不通过**原顶点。Catmull-Clark、Loop 都是
- **插值型**（interpolating）：极限曲面**通过**原顶点。Butterfly、Kobbelt 的一部分是

近似型光滑但形状会缩小，插值型不缩水但容易起波纹。工业动画基本都用近似型。

## 2. Catmull-Clark：四边形网格的老大

Edwin Catmull（后来是皮克斯 CTO、迪士尼动画总裁）和 Jim Clark（后来创立 SGI）1978 年一起提出的算法。给一个多边形网格（不限四边形，但迭代一次后所有面都变四边形），每次细分做三件事：

**Step 1 — 面点（face point）**：每个面 $F$ 的所有顶点求平均：

$$
\mathbf F = \frac{1}{n}\sum_{i=1}^{n} \mathbf V_i
$$

**Step 2 — 边点（edge point）**：每条边 $E$ 的两端点 + 两侧面点求平均：

$$
\mathbf E = \frac{\mathbf V_1 + \mathbf V_2 + \mathbf F_L + \mathbf F_R}{4}
$$

**Step 3 — 更新原顶点位置**：原顶点 $\mathbf V$ 及其邻域（$n$ 邻面的面点平均 $\bar{\mathbf F}$、$n$ 邻边中点平均 $\bar{\mathbf R}$）：

$$
\mathbf V' = \frac{\bar{\mathbf F} + 2\bar{\mathbf R} + (n-3)\mathbf V}{n}
$$

**Step 4 — 重连**：每个原面拆成 $n$ 个四边形，每个四边形由（一个原顶点、两个相邻边点、面点）构成。示意：

```
    V0 ●──E01──● V1              V0'●───E01──●F───E12──● V1'
       │       │                     │        │        │
      E30      E12       →           E30       E12
       │       │                     │        │        │
    V3 ●──E23──● V2              V3'●───E23──●F───E23──● V2'
```

一个 $n$ 边形迭代一次后拆成 $n$ 个四边形。**从第二次起所有面都是四边形**——这是 Catmull-Clark 的核心不变量，也是它偏爱四边形网格的原因。

**奇异点**（extraordinary vertex）：度数 $\ne 4$ 的顶点。四边形网格里绝大多数顶点度数是 4，少数是 3 或 5。奇异点周围的极限曲面**不是 $C^2$ 的**（一般只到 $C^1$），Catmull 和 Clark 原论文遗留问题，直到 2000 年代才被 Stam、Loop 等人给出精确评估方法。视觉上奇异点区域会有轻微不平滑，建模时尽量减少。

## 3. Loop 细分：三角形网格的对应物

Charles Loop 1987 年硕士论文里的算法。三角形专用，每次细分：

**Step 1 — 边点**：每条边 $E$ 的两端 $\mathbf V_1, \mathbf V_2$ 和两侧三角形另外两个顶点 $\mathbf L, \mathbf R$：

$$
\mathbf E = \frac{3(\mathbf V_1+\mathbf V_2) + \mathbf L + \mathbf R}{8}
$$

**Step 2 — 更新原顶点**：设顶点度数 $n$、邻居顶点 $\mathbf V_i$：

$$
\mathbf V' = (1 - n\beta)\mathbf V + \beta \sum_{i=1}^{n} \mathbf V_i
$$

Loop 原始的 $\beta$：

$$
\beta = \frac{1}{n}\left[\frac{5}{8} - \left(\frac{3}{8} + \frac{1}{4}\cos\frac{2\pi}{n}\right)^2\right]
$$

Warren 后来给的简化式在实践中一样好用：$\beta = 3/(8n)$（$n>3$）、$\beta=3/16$（$n=3$）。

**Step 3 — 重连**：每个三角形拆成 4 个（连三条边点得到中间倒三角）：

```
       V1                       V1
       ●                        ●
      ╱ ╲                      ╱ ╲
     ╱   ╲                    E12──E01
    ╱     ╲       →           ╱ ╲╱ ╲
   ╱       ╲                 ╱  ╱╲  ╲
  ●─────────●               ●─E02───●
  V0        V2              V0        V2
```

Loop 细分产出仍然是三角形网格，[网格数据结构](./多边形网格表示与数据结构.mdx)不用换，几何管线（法线、UV、光栅化）沿用。极限曲面在正常顶点处 $C^2$，奇异点处 $C^1$。

## 4. √3 细分：更慢的加密节奏

Kobbelt 在 2000 年提出的 √3 细分很特别——每次细分面数只增加 3 倍（√3 ≈ 1.732，边长缩小到 $1/\sqrt 3$，两次迭代边长缩小 3 倍），而不是常规的 4 倍。做法：

1. 每个三角形中心插入一个新点
2. 中心点与三角形三顶点连线（每个原三角形变成 3 个）
3. **翻转**原有的所有边，让每条边连接的是两个新中心点，而不是旧顶点

```
原三角形（3 个原顶点）：           插入中心 + 翻转边（对应 3 顶点变成新点相连）：
       ●                              ●
      ╱ ╲                             │╲
     ╱   ╲                            │ ●─中心
    ●─────●                           │╱
                                      ●
```

一次 √3 相当于 4 倍加密的"一半"——细分粒度更精细，可以做**自适应细分**时更平滑地过渡。缺点是拓扑操作复杂（边翻转），实现上不如 Catmull-Clark 直观。

## 5. 极限位置的直接计算

细分曲线/曲面的一个重要工具是**直接跳到极限位置**——不用迭代无数次。对 Catmull-Clark，一个正常顶点（度数 4）的极限位置是：

$$
\mathbf V_\infty = \frac{16}{36}\mathbf V + \frac{1}{36}\sum_{\text{邻面顶点}} + \frac{4}{36}\sum_{\text{直接邻居}}
$$

对 Loop 细分正常顶点（度数 6）：

$$
\mathbf V_\infty = \frac{3}{8}\mathbf V + \frac{1}{16}\sum_{i=1}^{6}\mathbf V_i
$$

极限法线也有公式（各方案不同）。这在**shadow map、碰撞检测、精确光线求交**里很有用——不需要显式细分网格就能查询极限曲面上的点。

## 6. 特征保留：折痕与角

上面所有规则都会把尖锐特征也磨平——建一个立方体做 Loop 细分，几次以后会变成一个类球体。真实建模不希望"这条边一定要保持锐利"被平滑掉。

**折痕（crease）标注**：给指定边打上 crease 标记，边点更新时用中点公式而非上面的加权公式：

$$
\mathbf E_{\text{crease}} = \frac{\mathbf V_1 + \mathbf V_2}{2}
$$

**尖角（corner）标注**：给顶点打上 corner 标记，顶点位置永不更新。

DeRose 等人在 1998 年的 Subdivision Surfaces in Character Animation 里推广了这套系统（皮克斯用它做动画角色），OpenSubdiv（皮克斯开源库）是工业标准实现。Blender、Maya、Modo 建模里的"crease weight"滑块就是它——0 到 1 之间的软折痕，控制细分深度多少次后失效。

## 7. 自适应细分：不该细的地方别细

均匀细分让整个模型 $\times 4$ 面数，屏幕上一片草叶和一个人脸细的程度一样，浪费。**自适应细分**（adaptive subdivision）按局部曲率、屏幕投影大小、视角距离决定细分次数。

判据几种：

- **平坦度**：控制点近似共面时停止细分
- **屏幕空间**：投影后每三角形小于阈值像素（比如 8×8）时停止
- **视角**：法线朝向背面的区域低细分（配合背面剔除）
- **轮廓**：轮廓（silhouette）附近多细分——那里几何缺陷最显眼

难点是**接缝**（T-junction）：邻居面细分次数不同时，共享边一侧多一个点、另一侧没有，出现裂缝。经典做法是让粗侧的面拆成三角形吸收细侧的新点，或者在着色器里做"stitching"缝合。

## 8. GPU 曲面细分：Hull 和 Domain 着色器

DirectX 11 / OpenGL 4.0 起，GPU 硬件支持了曲面细分流水线，在光栅化之前多两个阶段：

```
Vertex Shader
     ↓
Hull Shader          ← 每个 patch 计算细分因子
     ↓
Tessellator (固定功能)  ← 硬件按因子生成参数网格
     ↓
Domain Shader        ← 每个新顶点根据参数 (u,v) 计算实际位置
     ↓
[Geometry Shader]
     ↓
Rasterizer
```

**Hull Shader**（DX 命名，GL 叫 Tessellation Control Shader）：接收一个 patch（一组控制点，通常 3、4 或 16 个），输出：

- 修改后的控制点（可能做基变换）
- **细分因子**（tess factors）：外侧因子控制边上分几段、内侧因子控制内部密度

细分因子根据屏幕投影长度、视距、LOD 参数动态算，是自适应细分的机会窗口。

**Tessellator**：固定功能硬件单元，按 hull 给的因子在参数域 $(u,v)$ 上生成一堆参数化的新顶点。程序员管不着，只影响细分因子。

**Domain Shader**（GL 叫 Tessellation Evaluation Shader）：拿到每个新顶点的参数坐标 $(u,v)$，计算实际位置。这里可以：

- 求 Bézier/B-spline 曲面上对应点
- 采样 heightmap 做置换（displacement mapping）
- 计算 Phong 平滑（PN triangles）——只有位置和法线，无控制网

一个典型的 domain shader 主体：

```glsl
// Bézier patch 求值
vec3 evalPatch(vec2 uv) {
    // 三阶 Bernstein 权重
    vec4 Bu = bernstein3(uv.x);
    vec4 Bv = bernstein3(uv.y);
    vec3 p = vec3(0);
    for (int i = 0; i < 4; i++)
        for (int j = 0; j < 4; j++)
            p += Bu[i] * Bv[j] * cp[i*4+j];
    return p;
}
```

关于 GPU 曲面细分和管线其它阶段的关系，见 [顶点处理](../图形渲染管线/顶点处理与图元装配.mdx)。

## 9. LOD：细分作为 LOD 手段

**Level of Detail** 是"远处物体用低精度模型"这个朴素想法的通称。传统 LOD 是**离散**的：美术做 3 版模型（LOD0、1、2），运行时按距离切换。切换瞬间有跳变（LOD popping），得靠 alpha blend 或 dither 隐藏。

细分曲面天然是**连续 LOD**：细分次数就是密度参数，可以是分数（自适应细分因子）。GPU tessellation 里 tess factor 可以是 3.7 这种非整数——硬件会平滑插值，避免 popping。

新一代方案 Nanite（UE5）走得更远：把网格预处理成**簇层次**（cluster hierarchy），每个簇是几百面的小片段，运行时按屏幕投影选择合适 LOD 的簇拼装。本质是**连续几何细节**的极致工程化，理念和曲面细分一脉相承但换了实现路径。

## 10. 何时用细分曲面

一句话：**当你想要光滑曲面 + 任意拓扑 + 支持局部编辑时**。

| 场景 | 用不用 |
|---|---|
| 电影角色（人脸、生物） | 用，皮克斯以来的标准 |
| CAD 精确工业设计 | 不用，NURBS |
| 硬表面（枪械、机械） | 不用，直接三角网 + 硬边 |
| 地形、大规模场景 | 部分用，配合置换贴图和自适应细分 |
| 手机端游戏 | 慎用，CPU 细分内存开销大、GPU 细分老设备不支持 |
| 字体、SVG | 不用，见 Bézier |

细分曲面 + 隐式几何还有一种奇特的对话：隐式几何用等值面表达任意拓扑，可以自动光滑，天然适合融合和布尔运算——见 [隐式建模与体素](./隐式建模与体素.mdx)。
