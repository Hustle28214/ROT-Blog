# 典型非线性特性与性能改善

## 常见非线性

实际控制系统的非线性常来自执行器、传感器和机械传动：

- **饱和**：$y=\operatorname{sat}(Kx,\pm M)$。限制输出幅值，使大信号等效增益下降；积分器继续累积会产生积分饱和。
- **死区**：$|x|\le d$ 时输出近似为零。会降低小信号灵敏度，造成稳态误差或低频振荡。
- **继电器**：输出在 $\pm M$ 间切换。结构简单但可能形成极限环，高频切换还会引起抖振。
- **滞环**：输出不仅取决于当前输入，还取决于输入变化方向。它带来相位滞后与能量耗散，常见于磁性元件和机械间隙。
- **间隙（回差）**：输入反向时经过一段空程才带动输出，易产生相位滞后、振荡和定位误差。
- **摩擦**：库仑摩擦、黏性摩擦及静摩擦共同作用，可能导致爬行和粘滑运动。
- **速率限制**：约束 $|\dot y|\le v_{\max}$；即使幅值未饱和，也可能因变化过快而产生严重相位滞后。

线性化只在工作点附近有效。若非线性函数在平衡点可微，可取

$$
\Delta y\approx
\left.\frac{\mathrm df}{\mathrm dx}\right|_{x_0}\Delta x.
$$

继电器、死区拐点和摩擦切换处不可直接用单一导数描述，且局部线性稳定不代表全局稳定。

## 性能影响

非线性有时是有害约束，也可被有意利用。饱和、死区和间隙一般降低精度或稳定裕度；继电控制可提高大偏差时的控制作用；适当非线性阻尼可实现“大误差快、小误差稳”。评价时应同时关注平衡点、吸引域、极限环、峰值控制量和切换频率。

## 改善措施

1. **减小结构非线性**：消除机械间隙、降低摩擦、提高执行器量程与传感器分辨率。
2. **抗积分饱和**：条件积分、积分限幅或回算；饱和解除后可更快恢复。
3. **死区补偿**：使用近似逆模型或偏置补偿，但需限制补偿幅度，避免噪声附近频繁切换。
4. **滞环/摩擦补偿**：采用辨识模型前馈，并保留鲁棒反馈处理模型误差。
5. **抖振抑制**：设置合理滞环带、提高执行器带宽或采用连续近似；不能仅靠无限提高采样频率。
6. **增益调度与分段控制**：按工作区间切换参数，切换处应保证控制量连续并分析各区间及切换稳定性。
7. **限幅与参考整形**：限制设定值斜率、速度和加速度，避免激活速率限制或大幅饱和。

## 分析方法选择

- 工作点附近小扰动：线性化与局部稳定性分析；
- 单一非线性、近似正弦自振：描述函数法；
- 二阶自治系统、关注全局轨迹：相平面法；
- 多非线性或高阶复杂系统：李雅普诺夫法、数值延拓和时域仿真。

补偿后必须保留真实非线性模型进行全范围仿真，并用不同初值检查多稳态与吸引域；只验证某一条阶跃响应不足以证明非线性闭环安全。
