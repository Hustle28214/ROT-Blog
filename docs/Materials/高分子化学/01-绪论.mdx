# 绪论：从小分子到大分子

高分子化学研究的对象是**分子量在 $10^4$ 以上的化合物**。这个数量级并不是凭空划的：低于它，分子量对物性的影响还很敏感；高于它，链长再增加，力学、热学性质渐趋饱和。橡胶的弹性、纤维的强度、塑料的成型加工性，都建立在"链足够长"这个前提上。

## 1. 一些基本概念

**单体（monomer）** 是构成高分子的小分子原料。**结构单元（structural unit）** 是单体在高分子链中残留的重复片段。这两者不必等同：乙烯 $\text{CH}_2=\text{CH}_2$ 聚合得到 $-(\text{CH}_2-\text{CH}_2)-$，加成聚合中原子守恒；但己二酸和己二胺缩聚成尼龙 66 时，每形成一个酰胺键就脱去一分子水，结构单元和单体在原子组成上不同。

**聚合度（degree of polymerization, DP）** 描述链的长度。以结构单元数计，记作 $\overline{X}_n$；以单体单元数计，记作 $\overline{DP}$。对加成聚合两者相等；对缩聚，二元单体一分子对应半个结构单元，$\overline{X}_n = 2\overline{DP}$。这个换算在做分子量计算时经常出错，要小心。

**平均分子量** 有两种主流定义：

$$
\overline{M}_n = \frac{\sum N_i M_i}{\sum N_i}, \qquad \overline{M}_w = \frac{\sum N_i M_i^2}{\sum N_i M_i}
$$

$\overline{M}_n$ 是数均，$\overline{M}_w$ 是重均。数均对小分子敏感（端基分析、渗透压法测的都是数均），重均对大分子敏感（光散射法测的是重均）。二者比值 $\overline{M}_w / \overline{M}_n$ 称**多分散指数（PDI）**，反映分布宽度。理想的活性聚合可以做到 PDI 接近 1，工业自由基聚合通常在 2 附近，缩聚在 2 附近（Flory 分布）。

## 2. 分类：按什么维度切

**按主链元素**分：碳链、杂链（含 O、N、S）、元素有机（Si-O 主链的硅橡胶）。

**按几何形状**分：线型、支化、交联（网状）。交联密度是热塑与热固的分水岭：热塑塑料链间只有范德华力，加热可流动；热固树脂链间共价交联，加热只能分解不能重塑。橡胶硫化就是引入稀疏的硫桥，交联密度低到既保持流动性又提供回弹。

**按热行为**分：塑料、纤维、橡胶、涂料、粘合剂。这个分类不太严格——同样的 PVC，做管材是塑料，做增塑膜就是软塑料，加大量增塑剂就是革——**材料的名字取决于配方和加工，不完全取决于化学结构**。

**按聚合机理**分：连锁聚合、逐步聚合。这个划分才是高分子化学教材的主线。

## 3. 连锁聚合 vs 逐步聚合

这是全书的**分水岭**。潘祖仁教材把这两种机理反复对比，值得一开始就搞清楚差别在哪。

**连锁聚合（chain polymerization）**：由活性中心（自由基、阳离子、阴离子、配位络合物）引发，单体一个个连接到链上，速率极快。任何时刻反应体系里只有单体、极少量正在增长的活性链、以及已经死亡的高分子——**中间态几乎不存在**。所以连锁聚合体系的分子量从反应一开始就很高，转化率提高只是增加高分子链的**数目**，链长本身变化不大。

**逐步聚合（step-growth polymerization）**：官能团之间随机反应，二聚体、三聚体、四聚体…… 逐级累积。任何两个分子（哪怕都已经是低聚物）都可以继续反应，只要还带官能团。**分子量随转化率单调上升**，只有当转化率 $p$ 接近 1 时才能得到高分子。这就是 Carothers 方程 $\overline{X}_n = 1/(1-p)$ 的含义：$p=0.99$ 才有 $\overline{X}_n = 100$，$p=0.999$ 才有 $\overline{X}_n = 1000$。

对比几点：

| | 连锁聚合 | 逐步聚合 |
|---|---|---|
| 活性种 | 自由基/离子/络合物 | 官能团 |
| 分子量 vs 转化率 | 早期就很高，几乎不变 | 缓慢上升，末期陡增 |
| 反应速率 | 快，秒到分钟 | 慢，小时到天 |
| 中间产物 | 单体+高分子，几乎无中间体 | 各种低聚物共存 |
| 副产物 | 一般无 | 常有小分子（水、醇、HCl）脱出 |

## 4. 从合成到应用之间的三层桥梁

拿到一个新单体，走到最终产品，途中要跨三道门：

1. **合成**：怎么聚？选什么机理？温度、催化剂、溶剂？—— 这是本课程的主要内容。
2. **加工**：熔融流动、溶液纺丝、共混、成型 —— 属于高分子物理和加工工程。
3. **性能**：模量、强度、耐热、透光 —— 由结构（分子量、支化、结晶度、交联密度）决定。

三层之间的耦合很紧。举个反例：想做透明制品，就不能用高结晶度的 PE 或 PP，得用 PMMA、PS 或者非晶态 PC —— 这个"能不能透明"是**加工前就由化学结构决定的**。所以高分子化学不是孤立的合成课，它决定了后面所有加工和使用的自由度。

## 5. 高分子化学的历史线索

Staudinger 在 1920 年代提出"高分子是共价连接的长链"之前，胶体化学家坚持认为橡胶、蛋白质只是小分子的"胶体聚集体"。这场持续二十多年的争论直到 X 射线衍射和渗透压测定给出确凿证据才结束。Staudinger 1953 年获诺贝尔奖。

真正让高分子科学工业化的是三个人：

- **Carothers**（DuPont，1930s）：系统研究缩聚，发明尼龙 66；证明了逐步聚合定量关系。
- **Ziegler & Natta**（1950s）：开发过渡金属催化剂，实现乙烯低压聚合和丙烯的立构规整聚合。这是配位聚合的开端。
- **Szwarc**（1956）：发现阴离子活性聚合，第一次实现"分子量可控、分布极窄"的合成。是活性/可控聚合的鼻祖。

到 1980 年代以后，可控自由基聚合（ATRP、RAFT、NMP）、开环易位聚合（ROMP）、点击化学等继续拓展合成能力，让高分子化学从"造材料"走向"造结构精确的分子器件"。
