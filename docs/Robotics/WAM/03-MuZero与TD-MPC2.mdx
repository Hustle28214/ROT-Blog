# MuZero 与 TD-MPC2：只预测决策要用的东西

上一篇 [Dreamer 系列](./02-Dreamer系列.mdx)还在重建观测，这一篇的两个工作干脆把重建扔了。它们的共同立场是：世界模型不需要是人能看的模拟器，只要 latent rollout 对决策充分就行。做机器人的话这条路线特别值得看，因为它是少数明确以控制频率为设计约束的。

## 1. MuZero：value equivalence

[MuZero](https://arxiv.org/abs/1911.08265)（2019）学三个网络：

- 表征 $s^0 = h_\theta(o_{\le t})$，把观测历史压成初始 latent；
- 动力学 $s^k, r^k = g_\theta(s^{k-1}, a^k)$，在 latent 里往前推一步并给出即时奖励；
- 预测 $p^k, v^k = f_\theta(s^k)$，输出策略分布和价值。

关键在于损失里没有任何一项要求 $s^k$ 能还原回观测：

$$
\mathcal{L} = \sum_{k=0}^{K}\Big[\ell^r(u_{t+k}, r^k) + \ell^v(z_{t+k}, v^k) + \ell^p(\pi_{t+k}, p^k)\Big] + c\|\theta\|^2
$$

其中 $\pi_{t+k}$ 是 MCTS 搜出来的访问分布，$z_{t+k}$ 是 bootstrap 的价值目标。也就是说 latent 只被要求做到一件事：预测出的奖励、价值、策略跟真实搜索结果一致。这叫 value equivalence，模型可以学出任何内部表示，只要这三个量对得上。

推理时用 pUCT 在这个学到的 latent 里做蒙特卡洛树搜索。因为动力学是学出来的，MuZero 不需要环境规则，这才让同一套算法同时拿下了围棋、国际象棋和 Atari。

值得留意的副作用：这个 latent 完全没被观测锚定，所以你没法可视化它，也很难判断它在哪里错了。这个代价在真机上比在棋盘上要疼得多。

## 2. TD-MPC2：短视野规划 + 终端价值

[TD-MPC](https://arxiv.org/abs/2203.04955) 和 [TD-MPC2](https://arxiv.org/abs/2310.16828)（2024）把同样的思路搬到连续控制上，但换掉了树搜索。它学 encoder、latent 动力学、奖励和 $Q$，全都用 TD 目标训练，不重建观测。

规划的时候只在 latent 里滚很短的一段（默认 3 步），末端接上学到的价值兜住剩下的无穷视野：

$$
\max_{a_{t:t+H-1}} \; \mathbb{E}\Big[\sum_{k=0}^{H-1}\gamma^k \hat R(z_{t+k}, a_{t+k}) + \gamma^H Q(z_{t+H}, \pi(z_{t+H}))\Big]
$$

优化用 MPPI 这类采样式方法，并且拿一个学到的策略先验去初始化候选动作分布，省掉大量采样。这个组合我认为是这条线最实用的设计：短视野把模型误差的累积截断了，终端价值又把长期信息补回来，两边的缺点互相抵消。

TD-MPC2 相对第一版主要是把可扩展性做出来了：

- latent 用 SimNorm 做分段 softmax 归一化，把表示限制在一个有界的单纯形上，训练稳定性提升明显；
- $Q$ 用集成加 dropout，缓解过估计；
- 单套超参覆盖 80 多个任务，单个 317M 的模型可以同时管多种具身和不同动作维度。

## 3. 跟 WAM 的关系

这两个工作跟今天的 WAM 看起来很不一样，一个不生成像素，一个连观测都不重建。但落到机器人上，我觉得有三点是直接可借鉴的。

第一，闭环频率是硬约束，不是指标之一。TD-MPC2 之所以只滚 3 步，就是因为再多就跑不到控制周期里。[MotionWAM](./01-MotionWAM.mdx) 只做一次前向、不完整去噪，本质是同一个妥协逻辑，只是换到了视频扩散模型上。

第二，短视野 + 终端价值这个结构，在现在的 WAM 里几乎是缺失的。WAM 普遍靠 action chunk 撑住一小段时间，然后重新推理，等价于一个没有价值函数的短视野 MPC。长时任务的信息该由谁来提供，目前还没有好答案。

第三，value equivalence 提醒了一件容易被忽略的事：预测得像不等于预测得有用。视频模型能生成非常合理的未来帧，但这些帧里有多少信息真的被动作分支用上了，这是需要单独验证的，不能靠 FVD 之类的生成质量指标代替。
