# 参数曲线与曲面：用少量控制点描述连续几何

三角形网格能逼近任何曲面，但**没有解析形式**——想加密就重新细分，想在曲面上求切平面就得数值差分。CAD、字体、动画路径这些场景需要**光滑**、**可微**、**用少量参数描述**的几何，参数曲线曲面就是为此而生。这一章从 Bézier 讲到 NURBS，重点是每一步扩展"为了解决什么问题"。

## 1. 参数化的观念

一条二维曲线可以有三种表示：

- **显式** $y=f(x)$：能表达函数但表达不了竖直线、圆
- **隐式** $F(x,y)=0$：$x^2+y^2-r^2=0$ 表示圆，但从方程里"生成"点难
- **参数式** $\mathbf p(t)=(x(t), y(t))$：$t\in[0,1]$ 遍历一遍就画出曲线，天然可分段、可扩展到高维

参数式是图形学的默认选择。曲线是一维参数 $t$，曲面是二维参数 $(u,v)$。参数化的额外好处：**同一条几何形状可以有多种参数化**（比如匀速走 vs 变速走），这在弧长参数化、动画时间轴、纹理映射里各有用武之地。

## 2. Bézier 曲线：从 Bernstein 基说起

Bézier 曲线是最经典的参数曲线，两位法国汽车工程师 Pierre Bézier（雷诺）和 Paul de Casteljau（雪铁龙）在 1960 年代独立发明，前者发表得晚但推广得好，冠名权就归了 Bézier。

$n$ 次 Bézier 曲线由 $n+1$ 个**控制点** $\mathbf P_0, \mathbf P_1, \ldots, \mathbf P_n$ 定义：

$$
\mathbf B(t) = \sum_{i=0}^{n} B_i^n(t)\, \mathbf P_i, \quad t\in[0,1]
$$

$B_i^n(t)$ 是 Bernstein 多项式：

$$
B_i^n(t) = \binom{n}{i} t^i (1-t)^{n-i}
$$

三次 Bézier（$n=3$，四个控制点）最常用——Adobe Illustrator、字体轮廓（TrueType 是二次、PostScript/OTF 是三次）、CSS 缓动函数全是三次 Bézier：

$$
\mathbf B(t) = (1-t)^3 \mathbf P_0 + 3(1-t)^2 t \mathbf P_1 + 3(1-t)t^2 \mathbf P_2 + t^3 \mathbf P_3
$$

几个必知的性质：

- **端点插值**：$\mathbf B(0)=\mathbf P_0$、$\mathbf B(1)=\mathbf P_n$。曲线严格通过第一个和最后一个控制点
- **端点切向**：$\mathbf B'(0)=n(\mathbf P_1-\mathbf P_0)$、$\mathbf B'(1)=n(\mathbf P_n-\mathbf P_{n-1})$。所以拖动 $\mathbf P_1$ 就是调整起点切向
- **凸包性**：曲线完全落在控制点的凸包内。渲染时的粗略包围盒直接用控制点就行
- **仿射不变性**：对控制点做仿射变换等价于对曲线做同样变换。这就是为什么 SVG 里对路径做 transform 不用重算曲线上的点

## 3. de Casteljau 算法：递归线性插值

Bernstein 公式直接算 $\mathbf B(t)$ 数值稳定性差（阶乘、幂次都容易溢出）。**de Casteljau 算法**用递归线性插值来算，数值稳定且几何直观：

$$
\mathbf P_i^{k}(t) = (1-t)\mathbf P_i^{k-1}(t) + t\mathbf P_{i+1}^{k-1}(t)
$$

$\mathbf P_i^0 = \mathbf P_i$（初始控制点），最终 $\mathbf B(t) = \mathbf P_0^n(t)$。

以三次 Bézier 为例，画出来是这样：

```
     P0 ●───────● P1
        ╲       ╲
       Q0╲───────╲Q1
          ╲       ╲
        R0 ●───────● R1
            ╲     ╱
             ╲   ╱
              ● B(t)
                
     P1 ●───────● P2
        ╲       ╲
       Q1╲───────● Q2
     P2 ●───────● P3
```

每一步在相邻两点之间按 $t$ 做线性插值。$n$ 层递归后得到曲线上的点。这个算法还顺便完成**曲线细分**：中间的 $\mathbf Q$、$\mathbf R$ 点就是把曲线在 $t$ 处分成两段后各自的控制点。

递归细分让 Bézier 曲线可以自适应显示：控制点近似共线时曲线接近直线，直接用直线段代替；否则递归细分成两半继续判断。这是 SVG 和字体渲染的实际工程做法。

## 4. Bézier 的软肋与 B 样条的动机

Bézier 曲线漂亮，但用起来有两个问题：

1. **控制点数与阶数绑定**：想让曲线经过 20 个"控制"位置就得用 20 阶 Bézier，阶数一高数值就乱、震荡就来
2. **局部性差**：移动任何一个控制点，整条曲线都变。设计师改一个点看到整个字母都在动，抓狂

工程上的补救是**分段 Bézier**：把一条长曲线切成多段三次 Bézier，段与段之间保证连续性。这就是字体和 SVG 的做法。但段接头处的连续性得手动维护，麻烦。

**B 样条**（B-spline，B 代表 basis）从设计上解决这两个问题。它用一组**局部支撑**的基函数 $N_i^p(t)$ 替代 Bernstein 基：

$$
\mathbf C(t) = \sum_{i=0}^{n} N_i^p(t)\, \mathbf P_i
$$

$p$ 是 B 样条的**次数**（degree，比阶数少 1），$n+1$ 个控制点。基函数由**节点向量**（knot vector）$U = \{u_0, u_1, \ldots, u_m\}$ 定义，通过 Cox-de Boor 递推：

$$
N_i^0(u) = \begin{cases} 1 & u_i \le u < u_{i+1} \\ 0 & \text{otherwise}\end{cases}
$$

$$
N_i^p(u) = \frac{u-u_i}{u_{i+p}-u_i} N_i^{p-1}(u) + \frac{u_{i+p+1}-u}{u_{i+p+1}-u_{i+1}} N_{i+1}^{p-1}(u)
$$

关键性质：$N_i^p(u)$ 只在 $[u_i, u_{i+p+1}]$ 内非零。所以移动控制点 $\mathbf P_i$ 只影响 $p+1$ 段曲线，**局部性**成立。三次 B 样条改一点只影响 4 段，改动看得见但不会扩散到远处。

节点向量的选择决定曲线行为：

- **均匀节点** $\{0,1,2,\ldots\}$：所有基函数是彼此的平移，曲线不通过端点
- **准均匀（clamped）**：首尾节点各重复 $p+1$ 次，$\{0,0,0,0,1,2,\ldots,k,k,k,k\}$。曲线通过首尾控制点，最常用
- **非均匀**：任意节点间距。允许在某处"折角"（节点重复次数达到 $p$ 时）或调节曲率

## 5. 连续性：$C^k$ 与 $G^k$ 的区别

多段曲线拼接时，接头处的连续性有两套语言：

**参数连续性** $C^k$：前后两段的 $k$ 阶导数在接点处相等。$C^0$ 是位置连续（不断），$C^1$ 是切向量方向和大小都相等，$C^2$ 是曲率矢量也相等。

**几何连续性** $G^k$：前后两段的 $k$ 阶几何量（切线方向、曲率）在接点处相等，但幅度可以差一个正标量。$G^1$ 只要求切线方向一致（大小随意），$G^2$ 要求曲率矢量方向一致。

$C^k \Rightarrow G^k$，反之不成立。两条 $C^1$ 拼接的曲线看起来一定光滑，但两条 $G^1$ 拼接的曲线也一样光滑——**视觉上区分不出 $G^k$ 和 $C^k$**。所以工业设计（车身、字体）优先追求 $G^2$，数学表达简洁的场合优先 $C^2$。

关系直观：

```
C0/G0 : 位置连续，可能有尖点
        ╲     ╱
         ╲   ╱
          ● 
          
G1 : 切线方向一致，速度可不同
   ────────●────────
   
C1 : 切向量完全相等（方向+大小）
   ═══════●═══════
   
C2 : 加速度（曲率矢量）也相等，视觉最光滑
```

三次 B 样条**默认自动 $C^{p-1}=C^2$**——只要节点没重复，段间连续性自动到二阶。这正是 B 样条比分段 Bézier 强的核心：不用手动维护接头。

## 6. NURBS：处理圆锥曲线的最后一块拼图

B 样条能画任意光滑曲线，但**画不出精确的圆**。原因：圆是二次代数曲线（$x^2+y^2=r^2$），无法用多项式参数化表示（$\cos, \sin$ 不是多项式）。CAD 里画个圆得靠 B 样条近似，误差不能为零，工程上不可接受。

**NURBS**（Non-Uniform Rational B-Spline）通过引入**有理**形式解决这个问题。给每个控制点加一个权重 $w_i$：

$$
\mathbf C(u) = \frac{\sum_{i=0}^{n} N_i^p(u)\, w_i\, \mathbf P_i}{\sum_{i=0}^{n} N_i^p(u)\, w_i}
$$

分母的加权求和让曲线可以精确表达**圆锥曲线**（圆、椭圆、抛物线、双曲线）。原理是把 $n$ 维有理曲线看作 $n+1$ 维多项式曲线的中心投影：

$$
(x,y) \leftrightarrow (wx, wy, w)
$$

齐次坐标里做 B 样条，投回来就是有理 B 样条。$w=1$ 时退化回普通 B 样条。

NURBS 是 CAD 世界的通用语言——SolidWorks、CATIA、Rhino、AutoCAD 全用它。IGES、STEP、3DM 这些交换格式的核心就是 NURBS 曲面。工业界喜欢它是因为：

- 精确表达圆锥曲线和二次曲面（球、圆柱、圆锥）
- 局部支撑 + 参数连续性可控
- 通过节点插入、次数升阶等操作可以任意精细化
- 权重给了额外的"张力"自由度

代价是数学复杂度上升（有理函数的导数、求交、投影都比多项式麻烦），且**难以三角化**——渲染 NURBS 之前得先离散化成网格。这也是为什么游戏引擎极少直接用 NURBS：GPU 光栅化流水线只吃三角形。

## 7. Bézier 曲面：张量积扩展到二维

一维参数曲线扩展到二维参数曲面的最简单办法是**张量积**（tensor product）。$m\times n$ 的控制点网格 $\mathbf P_{ij}$，Bézier 曲面为：

$$
\mathbf S(u,v) = \sum_{i=0}^{m}\sum_{j=0}^{n} B_i^m(u)\, B_j^n(v)\, \mathbf P_{ij}
$$

$4\times 4$ 双三次 Bézier 曲面（bicubic Bézier patch）用 16 个控制点定义一片曲面，是 Utah teapot 的构造单位——Newell 1975 年用 32 片双三次 Bézier 曲面拼出的茶壶成了图形学的吉祥物。

计算 $\mathbf S(u,v)$ 上一点可以用**双 de Casteljau**：先固定 $v$ 对每一行控制点算一次 Bézier 得到 $m+1$ 个点，再对这些点用 $u$ 算一次。等价形式是先 $u$ 后 $v$，结果相同。

张量积曲面的问题：**要求控制点排成规则四边形网格**。任意拓扑的曲面（球、脑袋、树叶）无法用单片张量积表达，得多片拼接，接缝处连续性又是老问题。这催生了**曲面细分**（subdivision surface）——用离散网格 + 迭代规则替代参数方程，见 [曲面细分与几何细分](./曲面细分与几何细分.mdx)。

## 8. B 样条曲面与 NURBS 曲面

同样张量积推广：

$$
\mathbf S(u,v) = \sum_{i=0}^{n}\sum_{j=0}^{m} N_i^p(u)\, N_j^q(v)\, \mathbf P_{ij}
$$

NURBS 曲面加权：

$$
\mathbf S(u,v) = \frac{\sum_{i,j} N_i^p(u) N_j^q(v)\, w_{ij}\, \mathbf P_{ij}}{\sum_{i,j} N_i^p(u) N_j^q(v)\, w_{ij}}
$$

这就是 CAD 里"曲面"的定义。修剪曲面（trimmed NURBS）在 $(u,v)$ 参数域上再画一条 2D 曲线，把外侧裁掉，用来表达带孔洞的复杂曲面。

## 9. 渲染时的离散化

任何参数曲面最终要渲染都得离散化成三角形。基本做法是**均匀采样**：对 $(u,v)\in[0,1]^2$ 取 $N\times N$ 网格，每个格子拆成两个三角形。均匀采样在曲率剧烈变化的地方浪费点，在曲率大的地方又不够密。**自适应细分**基于曲率或屏幕投影误差决定局部密度，见 GPU 曲面细分（[Hull/Domain Shader](./曲面细分与几何细分.mdx)）。

也可以走完全不同的路——直接对参数曲面**光线求交**。给一条光线 $\mathbf r(t)=\mathbf o+t\mathbf d$，找它与 $\mathbf S(u,v)$ 的交点需要解 $\mathbf r(t)=\mathbf S(u,v)$，三未知量三方程，通常 Newton 迭代。慢，但省了三角化的内存开销。学术研究和某些离线渲染器（早期 PRMan、Reyes）走这条路，见 [光线追踪基本原理](../光线追踪/光线追踪基本原理.mdx)。

## 10. 一个务实的选型表

| 场景 | 选择 | 理由 |
|---|---|---|
| 字体轮廓 | 二次或三次 Bézier | 简单、可细分渲染 |
| SVG 路径 | 三次 Bézier | Adobe/PostScript 遗产 |
| CSS 缓动 | 三次 Bézier | 时间-进度曲线 |
| 动画路径 | Catmull-Rom / Hermite | 通过控制点，方便手 K 关键帧 |
| 通用建模曲面 | B 样条 | 局部编辑 + 自动连续性 |
| CAD 精确造型 | NURBS | 圆锥曲线 + 工业标准 |
| 有机建模、任意拓扑 | 细分曲面 | 见下一篇 |
