## 1. HID协议简介

相信大家平时都用过鼠标、键盘、触摸屏等设备，这些设备都使用了HID协议，HID协议是USB协议的子集，用于连接USB设备和计算机。

HID最新版本是HID 1.11，于2001年发布。

很多其实不需要人类交互行为的设备也都可以使用HID协议。HID类定义包含面向最终用户的多种输出类型。

![](https://rotblog-pic-1322347792.cos.ap-guangzhou.myqcloud.com/rot-blog-images/Electronic/%E5%B5%8C%E5%85%A5%E5%BC%8F/%E5%8D%8F%E8%AE%AE%E6%8E%A5%E5%8F%A3/HID/v2-c28af070d8a4debb7b7992aa09045066_r.jpg)

USB设备的信息存储在ROM的段中，这些段叫做描述符。描述符很重要，接口描述符可以将设备类型识别出来。就比如HID。


知道了设备属于hid设备，系统会选择hid驱动来处理这个设备。然后系统去看描述符，由此知道设备是什么、数据怎么传、数据格式是什么。

系统应该先读HID的类描述符，它相当于大哥，可以说出所有小弟HID设备的特征，比如报告描述符，协议描述符，物理描述符等。

![](https://rotblog-pic-1322347792.cos.ap-guangzhou.myqcloud.com/rot-blog-images/Electronic/%E5%B5%8C%E5%85%A5%E5%BC%8F/%E5%8D%8F%E8%AE%AE%E6%8E%A5%E5%8F%A3/HID/hid-descriptor.png)



## 2. HID功能特性

USB 设备被分成不同的 **设备类**（device classes）。同一类的设备通常有相似的数据传输需求；并且可以共用同一个类驱动程序。

HID设备的传输需求，对比音频设备等应该算是比较简单的。


一个 USB 设备可以是单一类，也可以由多个类组成。例如一个电话听筒可能同时使用：HID 类，AUDIO类，Telephony 类。他们写在接口描述符中，一个设备的不同接口可以属于不同类。

:::info
如果你非常熟悉面向对象式的编程，看到这里应该开始联想到了，既然有多个类，那很自然就有子类的出现。也就是说，HID设备的各种细分协议可以用子类来细化描述。

但是事实上，子类虽然存在，并没有被大规模使用。取而代之， HID 委员会鼓励大家使用报告描述符来描述它提供什么数据、数据格式是什么。

很奇怪吧，为什么？如果你也非常熟悉嵌入式开发，你就知道**这个世界的硬件设计真的是数不清的多**。硬件设计定位可以是交叉的，且大量，就拿一个最简单的例子。假设你现在要开发一款使用旋钮的键盘，那很简单，你直接把旋钮作为一个键盘的键盘键就好了。但是假设现在你的需求非常的奇葩，你需要做一个**旋钮，但这个旋钮既不是键盘按键，也不是鼠标按键，而是一个多媒体音量旋钮**。更要命的是，这个旋钮不仅要能旋转（顺时针 / 逆时针调节音量），还要能左右拨（拨一下切换上一曲 / 下一曲），还要能按下（按下直接静音）。就这么一个小旋钮，要横跨键盘、鼠标、多媒体控制三个子类——难道还要为它单独发明一个新子类吗？显然不现实。

我们还可以考虑一个更奇葩的需求，假设我们还要开发一个每个键都是旋钮的键盘，直接点击可以输入字母或者数字，但同时也可以对某个指定系统设置进行旋钮变更。虽然是一个离谱的例子，但是这种需求却可能真实存在。

这样想，我们怎么样都不应该用子类，用代称搞混儿子爹。而是应该发工牌，直接说明我是谁，我从哪里来，我是干啥的。
:::


在usb标准中，`bInterfaceClass = 0x03` 表示 HID 类设备。

在设备被检测到后，报告描述符立即由HID类驱动程序加载和解析。现有和新设备的协议，通过在报告描述符中混合数据类型来创建。

![](https://rotblog-pic-1322347792.cos.ap-guangzhou.myqcloud.com/rot-blog-images/Electronic/%E5%B5%8C%E5%85%A5%E5%BC%8F/%E5%8D%8F%E8%AE%AE%E6%8E%A5%E5%8F%A3/HID/hid-report-descriptor.png)

:::note
注意：

接口描述符的`bInterfaceProtocol`成员只有在`bInterfaceSubClass`成员声明设备支持引导接口时才有意义，否则为0。

并且协议码对应什么设备也有规定：

| Protocol Code | Description |
|---:|---|
| 0 | None |
| 1 | Keyboard |
| 2 | Mouse |
| 3–255 | Reserved |


:::
